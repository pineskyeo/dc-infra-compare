① 반복성 σr와 회차 간 정밀도 σrun

POR 3회만 씁니다. die마다 다른 값(공정 산포)을 빼고 남는 측정 정밀도를 두 성분으로 나눕니다. 이상치 die에 끌려가지 않도록 robust(중앙값·MAD)로 추정합니다.

ek = (Yk+1 − Yk) − median(Yk+1 − Yk) 이웃 회차 차이, 회차 전체 이동은 뺌
σr = 1.4826 · median|e − median(e)| / √2 반복성. MAD 기반 robust 추정. √2 = 두 번 잰 차이 → 1회
rk = mediandie(Yk − Ȳdie) 회차 k의 전체 이동
σrun2 = Var(rk) − (π/2)·σr2/n 회차 간 정밀도. 반복성 몫을 뺌

POR 3회, die별 값 (예시 24개 die)

이상치 die가 섞이면

실제 σr = 1. 표준편차는 이상치 die 몇 개에 몇 배로 부풀고, MAD 기반 robust 추정은 그대로입니다.

  • 반복 측정으로 측정 흔들림 분리: NIST/SEMATECH e-Handbook 2.4.4
  • 반복성·회차 간(중간) 정밀도 용어: ISO 5725-3, VIM
  • MAD, robust 척도: NIST/SEMATECH e-Handbook 1.3.5.6 (1.4826 = 정규분포에서 MAD를 σ로 바꾸는 상수)

② 정량한계 LoQ

1회 측정값을 숫자로 믿을 수 있는 최소 크기입니다. 이보다 작은 값은 "<LoQ"로 보고합니다.

σ = max( σr, Δx데이터/√12, Δx장비/√12, σblank )
LoD = 3.29·σ LoQ = 10·σ LoQ = 1회 측정의 상대표준편차가 10%가 되는 크기
Δx: 분해능(값 사이 가장 작은 간격). 계단값이라 3회가 같으면 σr = 0이 되는 것을 막음. √12 = 반올림 오차의 표준편차
blank: 원측정값이라 CALCVAL로 ITEM 단위로 바꿀 수 있을 때만. LoQblank = |평균| + 10·SD

LoQ 후보 중 가장 큰 값을 씀

구간조건판정 방법
정량|POR| ≥ LoQ⑤ TOST
검출~정량LoD ≤ |POR| < LoQ⑥ <LoQ 보고 일치
검출한계 이하|POR| < LoD⑥ <LoQ 보고 일치 (LoD는 구간 이름만 나눔)
  • LoD·LoQ: Currie, Anal. Chem. 40, 586 (1968); IUPAC 권고. 검출능력 ISO 표준은 ISO 11843
  • 분해능의 표준불확도 Δx/√12: GUM (JCGM 100) F.2.2.1 · 장비 분해능: Keysight P9001A 사양서 (item_info의 LEVEL·CALCVAL로 range 결정)

③ 편향 b와 90% 신뢰구간 (부호검정)

dj = DOEj − (POR1j + POR2j + POR3j)/3 die j마다
편향 b = median(d)
B ~ Binomial(61, 0.5): P(B ≤ 23) = 3.6% ≤ 5% < P(B ≤ 24) = 6.2%
90% CI = [ d(24) , d(38) ] 크기순 24번째 ~ 38번째. 실제 포함 확률 92.8%

die별 d (예시, 실제 편향 = +1%)

왜 24번째와 38번째인가

진짜 중앙값보다 작은 die 수는 동전 61번 던지기와 같습니다. 23개 이하일 확률 3.6%, 38개 이상일 확률 3.6%. 그래서 두 순서 값 사이에 진짜 중앙값이 있을 확률이 92.8%(≥ 90%)입니다. 값의 크기가 아니라 순서만 쓰므로 이상치가 얼마나 커도 구간이 움직이지 않습니다.

  • 부호검정 신뢰구간: Hollander & Wolfe, Nonparametric Statistical Methods
  • 90%인 이유: TOST는 한쪽 5% 검정 두 개 = 90% 신뢰구간 (Schuirmann 1987)

④ 동등 한계 ±Δ

편향이 이 안이면 같다고 봅니다. 실용 한계와 회차 예측 한계의 합입니다.

Δ = r·|POR 중앙값| + t0.95, J−1·√(1 + 1/J)·σrun
실용 한계 (r = 5%) + 회차 예측 한계: 같은 프로그램으로 다시 재도 DOE 1회가 POR J회 평균에서 벗어날 수 있는 폭 (90% 예측구간 한쪽)
J = 3 → t0.95,2 = 2.920, √(1+1/3) = 1.155 → 배수 3.37
A·V ITEM (item_info): Δ = max(Δ, 장비 정확도 한계), 장비 정확도 한계 = 1.645·√((UPOR2 + UDOE2)/3), U = a·|값| + b·range + c

동등 한계의 구성 (POR = 100)

POR 회차 수와 회차 예측 한계 배수

σrun을 회차 J개로만 추정하므로 1.645 대신 t를 씁니다. 회차를 늘리면 배수가 1.645·√(1+1/J)에 가까워집니다.

  • 실용 한계 r = 5%: 사내 정책 표준이 정하지 않음
  • 회차 예측 한계: 예측구간 (prediction interval), Hahn & Meeker, Statistical Intervals
  • 두 한계를 더하는 구성: 설계 "실무 허용 + 같은 프로그램 재측정 차이" 원칙을 옮긴 것
  • 장비 정확도 한계: Keysight P9001A 사양서, 균일분포 U/√3 (GUM 4.3.7)

⑤ 정량 구간: TOST 판정

H0: |b| ≥ Δ H1: −Δ < b < +Δ
검정 1: H0: b ≤ −Δ 기각 (5%) 검정 2: H0: b ≥ +Δ 기각 (5%)
두 검정 모두 기각 ⇔ 90% CI ⊂ (−Δ, +Δ)
평균판: t₁ = (d̄ + Δ)/(s/√n) > t0.95,n−1, t₂ = (d̄ − Δ)/(s/√n) < −t0.95,n−1. 여기서는 d̄ 대신 중앙값, t 구간 대신 부호검정 구간

신뢰구간과 ±Δ의 위치로 판정

판정조건뜻
동등−Δ ≤ CI 아래, CI 위 ≤ +Δ편향이 동등 한계 안이라고 증명됨
차이CI 아래 > +Δ 또는 CI 위 < −Δ편향이 동등 한계보다 크다고 증명됨
미결 · 해상도 부족걸침, CI 반폭 ≥ Δb가 0이어도 ±Δ 안에 못 들어감. 정밀도 부족
미결 · 경계걸침, CI 반폭 < Δ정밀도는 충분, b가 Δ 근처
  • Schuirmann, J. Pharmacokinet. Biopharm. 15, 657 (1987) · ASTM E2935 (두 측정의 동등성)

⑥ LoQ 미만: <LoQ 보고 일치

DOE 중심 = POR 중앙값 + b
차이 ⇔ [CI가 통째로 ±Δ 밖] AND [|DOE 중심| ≥ LoQ]
LoQ 미만 값은 숫자 대신 "<LoQ"로 보고. DOE 중심도 LoQ 미만이면 둘 다 "<LoQ"라 보고가 같음. die 61개의 중심은 die 하나보다 정밀해서 LoQ 미만에서도 비교 가능

POR 중심, DOE 중심, LoQ

일부 die만 바뀐 경우(예: 몇 개 die만 누설)는 중심이 거의 안 움직여 차이가 되지 않습니다. 그런 경우는 참고 지표의 이상치 die 수로 따로 봅니다.

  • LoQ 미만은 "<LoQ"로 보고: IUPAC 권고, Currie (1968)
  • 두 조건의 조합: 설계

참고 지표 (판정에 쓰지 않음)

t-test (대응)

t = d̄ / (sd/√n), df = n − 1
H0: 평균 차이 = 0. 마진이 0이라 "같다"를 증명하지 못함

이번 데이터(정량 5,398개)에서 t-test는 DOE vs POR 2,617개를 유의차로 냈고, 그중 2,599개는 TOST 동등입니다. POR 회차끼리 비교해도 2,253개(42%)가 유의차입니다. 같은 프로그램도 구분하지 못하므로 동등 판정에 쓰지 않습니다.

  • NIST/SEMATECH e-Handbook 7.3.1.1
