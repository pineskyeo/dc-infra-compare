공부하기

LoQ와 10배

숫자로 믿고 비교할 수 있는 가장 작은 크기.

  • 한 번 잴 때 흔들림 σ는 값이 작아도 거의 그대로다.
  • 그래서 값이 작을수록 흔들림이 값에 비해 커진다.
  • 흔들림이 값의 10%인 곳이 LoQ(= 10σ). 그 아래는 숫자 대신 '<LoQ'로 본다.
  • POR가 LoQ 아래면, DOE 구간이 LoQ를 통째로 넘어야 차이를 본다.

쓰는 단계: ③ LoQ와 ITEM 유형 · ⑥ 판정 3단계

전문10배의 유래 · σ 후보와 √12 · 2단계 규칙 · 근거 · 코드

10배는 어디서 나오나

RSD = σ / 값 값에 비한 흔들림 (상대표준편차) RSD ≤ 10% ⇔ 값 ≥ σ / 0.1 = 10σ LoQ = kQ · σ, kQ = 1 / (정한 RSD) = 10 LoD = 3.29 · σ = (1.645 + 1.645) · σ

같은 장비로 같은 die를 다시 재는 흔들림 σ는 값의 크기와 거의 상관없다. 그래서 값이 작을수록 RSD가 커진다. 'RSD 10% 이하면 숫자로 믿는다'를 겨우 만족하는 가장 작은 값이 LoQ = 10σ이다. kQ = 10은 IUPAC 기본값이고, 통계에서 저절로 나온 수가 아니라 '10% 정밀도면 믿는다'는 선택이다. LoD의 3.29는 없는데 '있다'고 할 확률 5%와 있는데 '없다'고 할 확률 5%를 묶은 값이다1.

σ는 세 후보 중 가장 큰 것

σ = max(σdie, 데이터 분해능 / √12, 장비 분해능 / √12) LoQblank 가 더 크면 LoQ = LoQblank

값이 계단(간격 Δx)으로만 찍히면 실제 값은 계단 한 칸 안 어디든 같은 확률로 있을 수 있다. 폭 Δx 균일분포의 분산은 Δx²/12 라 표준편차는 Δx/√12 = 0.29·Δx 이다. 반복 값이 모두 같게 찍혀 σdie = 0이어도 LoQ가 0이 되지 않게 아래를 받친다2. 데이터 분해능은 POR·DOE 고유값의 이웃 차 최솟값으로 정한다 (내부 근사)2. blank 시료로 구한 LoQ가 더 크면 그 값을 쓴다3. 결과 표의 limit_source 가 어느 후보를 썼는지 적는다.

예제 '계단 값': 값 간격 2 µV → 2 µV/√12 = 0.58 µV < σdie 2.10 µV → σdie를 쓴다, LoQ = 21.0 µV. 예제 '정량 · 선형': 0.001 Ω/√12 = 0.00029 Ω < σdie 0.98965 Ω → LoQ = 9.8965 Ω.

LoQ의 σ에는 σrun을 넣지 않는다 (반복성만). 문헌의 정량한계는 결과 하나의 모든 분산 성분을 넣으라고 하므로, 회차 이동(σrun)이 큰 ITEM은 LoQ가 작게 잡힌다. 이 문서의 설계 선택이다 내부 기준.

2단계 LoQ 판정 (|m| < LoQ)

DOE 구간 = m + [L, U] DOE 값이 있을 만한 범위 ① 이동이 ±Δ 안 (1단계 동등) → 동등 <LoQ 보고 일치 ② DOE 구간이 통째로 |x| ≥ LoQ 가 아님 → 동등 LoQ 아래이거나 LoQ 선에 걸침 ③ DOE 구간이 통째로 |x| ≥ LoQ, 이동이 ±Δ 밖 → 차이 ④ DOE 구간이 통째로 |x| ≥ LoQ, 이동이 ±Δ 에 걸침 → 미결

위에서부터 처음 맞는 줄을 쓴다. LoQ 아래 값은 숫자 대신 '<LoQ'로 보므로, 두 조건의 보고가 같은지를 본다. DOE 구간이 LoQ 선에 걸쳐도 '<LoQ'일 수 있어 동등으로 둔다. 구간 전체가 LoQ 선을 넘어야 보고가 숫자로 바뀐 것이다.

'<LoQ'로 보고해 같다고 보는 규칙은 내부 기준이다. 결과를 있는 그대로 보고하라는 반대 방향 권고도 있다4. ITEM 유형의 '바닥 아래'(cls_level)는 POR 값만으로 다시 구한 LoQ로 정하므로, DOE 값까지 본 판정의 LoQ와 조금 다를 수 있다.
