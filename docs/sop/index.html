DC Test 동일성 검증

같은 die를 기준 조건(Reference)과 비교 조건(Candidate)으로 재서, 두 조건을 같다고 볼 수 있는지 측정 항목(ITEM)마다 판정하는 절차 · 장비, 프로브카드, 측정 조건 중 무엇이 바뀌어도 같은 방법

약어·용어 · 정량한계(LoQ, Limit of Quantitation) · 신뢰구간(CI, Confidence Interval) · 두 번의 한쪽 검정(TOST, Two One-Sided Tests) · 회차(run)

검증 흐름

* 정량한계 미만 → ④ 신뢰구간과 ⑤ 허용 범위를 그대로 써서 ⑥에서 LoQ 판정(DOE 수준 구간을 LoQ와 비교)

흐름을 글 목록으로 보기
  1. ⓪ 표본 크기 정하기 · 예비 측정으로 J와 die 수 확인 → ① · 예시: J 3 · die 60개 · 최소 여유 0.6067
  2. ① 반복 측정 · 같은 die를 기준 조건 J회 + 비교 조건 1회, 매번 재터치다운 → ② · 예시: 기준 3회 + 비교 1회 × die 60개
  3. ② 흔들림 구하기 · 반복성 σdie, 회차 이동 σrun → ③ · 예시: σdie 0.98965 · σrun 0.50389
  4. ③ 정량한계(LoQ)로 구간 나누기 · 중앙값 ≥ LoQ면 정량 → ④ · 정량한계 미만 → ④ 신뢰구간과 ⑤ 허용 범위를 그대로 써서 ⑥에서 LoQ 판정 · 예시: LoQ 9.8965 · 중앙값 100 → 정량
  5. ④ 차이(편향)와 90% 신뢰구간 구하기 · 편향 b와 90% 신뢰구간 → ⑤ · 예시: b 0.786 · CI [0.610, 1.102]
  6. ⑤ 허용 범위 Δ 정하기 · 실용 한계 + 회차 예측 한계 → ⑥ · 예시: Δ 6.699 (5.0 + 1.699)
  7. ⑥ 판정 · 1단계 TOST → 2단계 LoQ 판정(LoQ 미만) → 3단계 유형별 판정(1·2단계에서 동등이 아닌 ITEM) → 동등 / 차이 / 미결 · 미결·차이일 때만 → ⑦ · 예시: CI [0.610, 1.102] ⊂ [−6.699, 6.699] → 동등
  8. ⑦ 미결·차이일 때 다음 행동 · 회차 추가, 측정 조건 점검, 사람 판정 기록 · 예시: 예시는 동등이라 해당 없음
기호뜻
J기준 조건 반복 회차 수
σdie반복성 · 같은 die를 다시 잴 때의 흔들림
σrun회차 이동 · 회차마다 모든 die가 함께 움직이는 크기
ddie별 차이 = 비교 조건 − 기준 조건 J회 평균
b편향 · d의 중앙값
Δ허용 범위 · 차이가 이 안이면 같다고 보는 한계

판정 결과 세 가지

기준 조건을 다시 재도 생기는 차이보다 크지 않으면 같다고 봄

동등

비교 조건을 기준 조건과 같다고 봄

합성 예시 ITEM 판정 = 동등

차이

비교 조건이 기준 조건과 다르다고 봄
