개요

DC Test 동일성 검증

DC Test 측정 항목(ITEM)마다 바꾼 조건(DOE)이 지금 조건(POR)과 같다고 볼 수 있는지 판정하는 절차.

공정이나 장비를 바꿀 때, 같은 die를 지금 조건으로 여러 번, 바꾼 조건으로 한 번 잽니다. 측정은 늘 흔들리므로 바뀐 정도를 90% 구간으로 잡고, 그 구간이 미리 정한 허용폭 Δ 안에 들어오면 같다고 봅니다. 결과는 ITEM마다 동등 · 미결 · 차이 셋 중 하나입니다.

전체 흐름

두 가지 읽기

따라하기실행 방법부터 ⓪~⑦ 단계를 차례로. 예제 ITEM 하나를 끝까지 따라갑니다. 공부하기중앙값, 90% 구간, TOST, LoQ 같은 개념을 그림으로 익힙니다.

예제 ITEM 유형

유형마다 예제 하나를 골라 모든 단계에서 같은 값을 따라갑니다. 숫자는 합성 데이터를 실제 도구로 판정한 결과입니다.
