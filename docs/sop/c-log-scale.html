잡음이 값에 비례하면 log

배율로 보는 판정.

  • die마다 값이 몇 배씩 다르고, 흔들림도 값에 비례하는 ITEM이 있다.
  • 이런 ITEM은 차이(DOE − POR)가 큰 die에서만 크게 나온다.
  • log 눈금에서는 흔들림 폭이 모든 die에서 같다.
  • 그래서 배율(DOE ÷ POR)을 log로 바꿔 TOST 한다.

척도 판별: 잡음 기울기

die 마다: x = log10(POR 회차 평균), y = log10(POR 회차 표준편차) noise_slope = (x, y) 의 Theil–Sen 기울기 (95% 구간 noise_slope_lo … hi) spread_robust = 3.45 × IQR(log10|die 평균|) 값이 걸친 자릿수 (P1~P99) scales 표에 그룹의 log·linear 가 있으면 → 표 값 spread_robust < 0.3 이거나 기울기를 못 구함 → 판별 불가 noise_slope ≥ 0.7 → log 그 밖 → linear

잡음이 값과 상관없이 일정하면 기울기는 0 근처, 값에 비례하면(값 10배 → 잡음 10배) 1 근처다. Theil–Sen은 점 두 개씩 이은 기울기들의 중앙값이라 튀는 die에 강하다. 값이 걸친 폭이 0.3 자릿수(약 2배)보다 좁으면 기울기를 믿을 수 없어 판별 불가로 둔다. 기울기는 평균·표준편차가 양수인 die만으로 구한다.

log TOST

Lij = log10|PORij|, wi = log10|DOEi| di = wi − (Li1 + … + LiJ) / J die 의 log 배율 중앙값과 부호검정 90% 구간 → TOST 1단계와 같은 방법 Δlog = log10(1 + r) + σrep,log, σrep,log = mediani SDj(Lij) log10(1.05) = 0.0212 배율 5%가 log 에서 더하는 폭

구간과 판정 규칙은 1단계와 같다12. 값에 0이 없고 부호가 하나일 때만 계산한다. log 판정에는 LoQ 구간이 없다: log 값이 0 근처라는 것은 그 단위에서 1 근처라는 뜻일 뿐이라 단위를 바꾸면 달라진다. 참고 열 verdict_log_run은 회차 항을 선형처럼 t·√(1+1/J)·σrun,log로 둔 판정이다. 어느 허용폭을 쓸지는 정하는 중이다 내부 기준.

배율로 읽기: 10d − 1 이 % 변화다. 예제 '정량 · 배율(log)': 이동 중앙값 0.01617 → ×1.038 (3.8% 증가), Δlog 0.02758 → 배율이 10−0.02758 = 0.938 ~ 100.02758 = 1.066 안이면 같다.
