t-test와 TOST

이 쪽이 답하는 질문

t-test(짝지은 t 검정)와 두 번의 한쪽 검정(TOST, Two One-Sided Tests)은 각각 무엇을 묻나 · 합성 예시 측정 항목(ITEM)에서 t-test는 유의차(p = 4.2e-07)인데 판정은 왜 동등인가 p = 합성 예시 도구 출력의 참고 지표

쉬운 말로

  • t-test: die별 차이 d의 평균이 0인지 묻는 검정. 0이 아니라고 보이면 '유의차'1
  • TOST: 차이가 ±Δ 안인지 묻는 검정. 90% 신뢰구간(CI, Confidence Interval)이 ±Δ 안이면 동등2
  • 질문이 다름: t-test 유의차 = '차이가 0은 아님'. 실무상 다르다는 뜻은 아님. ±Δ 안의 작은 차이도 유의차로 나옴 내부 기준(문헌 근거 없음)
  • die가 많고 잡음이 작을수록 t-test는 실무상 의미 없는 작은 차이도 유의차로 잡음 (식의 분모 sd/√n이 n과 함께 작아짐) 내부 기준(문헌 근거 없음)
  • 회차(run) 통째 이동(σrun)도 차이로 잡혀, 같은 조건을 다시 재도 유의차가 나옴: 예시 ITEM의 기준 조건(Reference) 회차끼리 t-test 3/3 유의차 합성 예시 도구 출력의 참고 지표 내부 기준(문헌 근거 없음)
  • 그래서 판정(⑥ 판정)은 TOST 하나. t-test는 결과 읽는 법의 참고 지표로만 기록. 도구도 계산만 하고 판정에 안 씀

더 자세한 쉬운 말은 아래 쉬운 말 더 보기

보충
  • 이 방법의 TOST는 d의 평균 대신 중앙값 b, t 구간 대신 부호검정 구간을 씀 (⑥ 판정 수식 절, 부호검정 신뢰구간)
  • 결과 읽는 법에서 t-test는 참고 지표 칸에만 나옴. 판정 칸과 섞어 읽지 않음

수식

t-test: t = d̄ / (sd/√n), |t| ≥ t1−α/2, n−1 → '차이 0' 기각 → 유의차
TOST: 90% CI ⊂ (−Δ, +Δ) → 동등

그림

여기서 볼 것 · 같은 자료, 같은 막대인데 질문이 다름 · 0 한 점과 비교하면 0이 막대 밖이고 t-test도 p = 4.2e-07로 유의차 · ±Δ 폭과 비교하면 막대가 띠 한가운데라 동등 · 기준 조건끼리도 3/3 유의차 → t-test 유의차는 '실무상 다르다'는 뜻이 아님
