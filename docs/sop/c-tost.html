개념 익히기 · 9 / 11

TOST와 동등 · 차이 · 미결

TOST = 한쪽 5% 검정 두 번. '편향 > −Δ'와 '편향 < +Δ'를 둘 다 보이면 동등. 90% 신뢰구간이 ±Δ 안에 드는 것과 같음

왜 쓰나

'차이를 못 찾음'을 '같음'으로 잘못 읽지 않게 함

자세히
  • 보통 검정은 차이를 보이는 도구. die가 적으면 차이가 있어도 '차이 없음'이 나옴
  • TOST는 같음을 직접 보여야 동등. 보이지 못하면 미결
  • 구간이 ±Δ 안이면 동등, 통째로 밖이면 차이, 걸치면 미결 내부 기준

그림

구간을 옮기면 판정이 동등 → 미결 → 차이로 바뀜

자세히
동등 · 미결 · 차이

동등 구간 전체가 ±Δ 안

90% 신뢰구간판정이유
[−1.0, 2.0]동등구간 전체가 ±Δ 안
[5.5, 8.0]미결구간이 +Δ 6.686에 걸침
[7.5, 9.5]차이구간 전체가 +Δ 6.686 밖

예시 숫자

Δ 6.686에서 구간 [−1.0, 2.0] 동등, [5.5, 8.0] 미결, [7.5, 9.5] 차이

자세히
Δ = 6.686
[−1.0, 2.0] ⊂ (−6.686, +6.686) → 동등
5.5 < 6.686 < 8.0 → 미결
7.5 > 6.686 → 차이

합성 예시이며 실행 결과가 아닙니다.
