TOST와 동등 · 차이 · 미결

이 쪽이 답하는 질문

두 번의 한쪽 검정(TOST, Two One-Sided Tests)은 무엇을 보나 · 90% 신뢰구간(CI, Confidence Interval) [0.610, 1.102]와 허용 범위 ±6.699로 동등 · 차이 · 미결을 어떻게 가르나

쉬운 말로

  • 보통 검정(t-test(짝지은 t 검정))은 '차이가 있다'를 보이는 도구. 차이를 못 찾았다고 같다는 뜻이 아님. die가 적으면 큰 차이도 놓침3
  • 반대로 die가 많으면 실무상 무시할 작은 차이도 유의차로 나옴. 예시 t-test p = 4.2e-07, 기준 조건(Reference) 회차끼리 견줘도 3쌍 모두 유의차 ⑥ 참고 지표, t-test와 TOST
  • TOST는 같음을 직접 보임: '편향 > −Δ'와 '편향 < +Δ'를 한쪽 5% 검정으로 따로 확인해 둘 다 통과하면 동등1
  • 두 검정을 한 번에 보는 방법 = 90% CI가 (−Δ, +Δ) 안에 통째로 들어가는지 봄. 한쪽 5%씩 두 번이라 90%1
  • TOST 이름 뜻: 한쪽 검정(One-Sided Test)을 두 번(Two)
    • → ① 편향 > −Δ ② 편향 < +Δ, 각각 한쪽 5%
    • → 둘 다 통과 ⇔ 가운데 90% CI가 (−Δ, +Δ) 안
    • → 같은 판정1
  • 판정은 세 갈래: 동등 · 차이 · 미결. 같음도 다름도 보이지 못하면 미결 내부 기준(문헌 근거 없음)2

더 자세한 쉬운 말은 아래 쉬운 말 더 보기

보충
  • 정량한계(LoQ, Limit of Quantitation) 미만 ITEM은 ⑥에서 TOST 대신 '<LoQ 보고 일치'로 봄. 이 갈래도 ④의 CI와 ⑤의 Δ를 씀
    • → ⑥ 판정
  • 미결 · 차이가 나오면 ⑦ 미결·차이일 때 다음 행동

수식

H01: b ≤ −Δ, H02: b ≥ +Δ → 둘 다 한쪽 5%에서 기각 ⇔ 90% CI ⊂ (−Δ, +Δ)
한쪽 5% 검정 두 번 = 양쪽 끝에서 5%씩 뺀 90% 구간 하나가 ±Δ 안에 있는지

90% 신뢰구간판정이유
[0.610, 1.102] (예시 ITEM)동등구간 전체가 ±6.699 안
+Δ에 걸친 구간미결구간이 +6.699에 걸침(경계)
+Δ보다 통째로 위인 구간차이구간 전체가 +6.699 밖

여기서 볼 것 · 판정은 b 한 점이 아니라 구간 전체의 자리로 정함. 구간 끝 하나라도 ±Δ 선을 넘으면 더는 동등이 아님

이 구간을 점 하나로 찍은 그림이 판정 지도 → 판정 지도는 왜 삼각형인가 (움직이는 그림)

여기서 볼 것 · b 4까지는 98.0% 이상 동등. b가 Δ 중앙값 6.409 둘레(5~7)를 지날 때 미결이 가장 많고(b 6에서 20.6%), b 10이면 99.6% 차이. 미결은 '같다'와 '다르다' 사이 경계 몫

쉬운 말 더 보기

  • 예시: [0.610, 1.102]가 ±6.699 안
    • → 동등 0.610 · 1.102 = ④ 차이(편향)와 90% 신뢰구간 구하기, 6.699 = ⑤ 허용 범위 Δ 정하기

예시 계산

예시 데이터: 합성 예시 die 6개 표

  1. 90% CI = [0.610, 1.102] ④ 차이(편향)와 90% 신뢰구간 구하기 · 부호검정과 중앙값 90% 신뢰구간 · 중앙값의 90% 신뢰구간 구하는 법
  2. Δ = 5.0 + 1.69896 = 6.69896 ≈ 6.699 ⑤ 허용 범위 Δ 정하기 · 허용 범위 Δ
  3. 아래 검정: 아래 끝 0.610 > −6.699 → '편향 > −Δ' 통과
  4. 위 검정: 위 끝 1.102 < +6.699 → '편향 < +Δ' 통과
  5. [0.610, 1.102] ⊂ (−6.699, +6.699) → 동등. 도구 판정도 동등, 이유 '90% 신뢰구간이 ±Δ 안'
  6. 구간이 ±Δ 안에 통째로 있으니 CI 반폭도 Δ보다 작음 → 해상도 부족 미결 아님
  7. 참고: t-test p = 4.2e-07 → 유의차가 있어도 판정은 동등. t-test는 판정에 안 씀3
