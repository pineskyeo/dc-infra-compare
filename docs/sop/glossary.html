자주 나오는 말

ITEM (측정 항목)
판정 단위. 판정은 ITEM마다 따로 한다.items.csv 한 줄 = ITEM 하나. 열 ITEM, 익명 번호 ID.
die
wafer 위 칩 하나. 판정의 표본 하나.짝짓기 키 WAFERID, COORD_X_Y, ITEM 으로 POR·DOE 의 같은 die 를 맞춘다. 열 n_die.
POR (기준 조건)
지금 쓰는 조건. 같은 die를 J번 잰다.옛 판의 기준 조건(Reference, Ref). 열 POR1_mean …, por_median.
DOE (비교 조건)
바꾸려는 조건. 같은 die를 1번 잰다.옛 판의 비교 조건(Candidate, Cand). 열 DOE_mean.
회차 (run)
같은 die들을 한 차례 모두 재는 것.POR 회차마다 --por 하나 (combos.ini 의 por 한 줄).
d (die별 차이)
die 하나의 DOE 값 − 그 die의 POR J번 평균.di = DOEi − (PORi1 + … + PORiJ) / J1.
이동 (shift, b)
d 들의 가운데 값. ITEM이 얼마나 바뀌었나.b = median(d). 열 center. 옛 판 이름 '편향'.
90% 구간
이동이 있을 만한 범위. 판정은 이 구간 전체로 본다.부호검정 구간 [d(k), d(n−k+1)], k = P(W ≤ k−1) ≤ 0.05 인 가장 큰 정수, W ~ 이항(n, ½)2. 열 ci_low, ci_high. 옛 판 이름 신뢰구간(CI).
허용폭 Δ
이동이 이 안이면 같다고 보는 폭.Δ = r·|POR 중앙값| + t0.95, J−1·√(1 + 1/J)·σrun, r = 0.05. 앞은 5% 몫(내부 기준)3, 뒤는 회차 몫4. 열 delta = policy_margin + run_margin.
TOST
같음을 직접 보이는 검정. 90% 구간이 ±Δ 안이면 동등.두 번의 한쪽 검정(Two One-Sided Tests). −Δ ≤ L, U ≤ Δ → 동등, L > Δ 또는 U < −Δ → 차이, 걸침 → 미결56.
LoQ (정량한계)
숫자로 믿고 비교할 수 있는 가장 작은 크기.LoQ = 10σ, σ = max(σdie, 데이터 분해능/√12, 장비 분해능/√12), blank LoQ 가 더 크면 그것7. 열 LoQ, limit_source.
σdie (반복성)
같은 die를 다시 잴 때의 흔들림.1.4826 × MAD(이웃 회차 차이) / √28. 열 sigma_die.
σrun (회차 이동)
회차마다 모든 die가 다 같이 밀리는 크기.√(회차 중앙값들의 분산 − (π/2)·σdie²/n), 안이 0보다 작으면 09. 열 sigma_run.
측정 정밀도
측정 흔들림을 값 크기 대비 %로. 낮을수록 좋다.100 × √(σdie² + σrun²) / |POR 중앙값|10. 열 meas_precision_pct, sigma_meas. compare 의 요약 지표.
ITEM 유형
POR 값만 보고 정한 ITEM의 종류. DOE는 안 본다.8축 cls_valid · cls_sign · cls_level (0 중심 · 바닥 아래 · 바닥 근처 · 정량) · cls_resolution (계단 · 연속) · cls_shape · cls_noise · cls_scale (log · linear · 판별 불가) · cls_run.
판정 길 (route)
ITEM 유형에 맞춰 3단계에서 다시 보는 방법.위에서부터 처음 맞는 길: 제외 → 한계 비교 → 절대 허용폭 → LoQ 판정 → log TOST → 선형 TOST. 열 route, route_note.
최종 판정 (verdict_final)
ITEM의 판정 하나. 동등 · 미결 · 차이 · 판정 제외.1·2단계 판정(verdict)이 동등이면 그대로. 아니면 판정 길의 판정이 동등·차이·미결일 때 그것, 아니면 1·2단계 판정. 집계와 차이·미결 목록은 이 열 기준.
판정을 정한 곳 (verdict_basis)
최종 판정이 어느 단계·방법에서 나왔나.linear (1단계 TOST) · loq (2단계 LoQ 판정) · log (log TOST) · abs (절대 허용폭) · accuracy (장비 정확도 폭) · limit (한계 비교).
절대 허용폭 (abs_delta)
값 크기와 상관없는 고정 허용폭. 0 근처·계단 값에 쓴다.같은 90% 구간을 ±abs_delta 로 TOST (verdict_abs). 그룹 abs_tol 파일(group,abs_delta) 값, 없으면 0 중심은 LoQ, 계단은 max(Δ, 값 간격), 계단이고 바닥 근처면 장비 정확도 폭까지.
'<LoQ 보고 일치'
POR도 DOE도 LoQ 아래라 둘 다 '<LoQ'로 적히니 같다고 본다.2단계 LoQ 판정. DOE 구간 = POR 중앙값 + [L, U] 이 통째로 LoQ 이상이 아니면 (아래이거나 LoQ 선에 걸침) 동등. reason 에 '<LoQ 보고 일치'. 내부 기준11.
판정 제외
판정할 것이 없는 ITEM. 예: 값이 모두 같음.원인 (1) 중심·구간 NaN·inf (2) 회차 0값 (3) 모든 값 같음 (4) die 산포 0 (정량 구간, 값 간격 ≥ 0.1·Δ 일 때만) (5) POR 중앙값 0 이고 σrun 0 (정량 구간만). 맞는 원인을 모두 이 순서로 reason 에. die 수 부족은 판정 제외가 아니라 미결.
compare 판단 기준
예전보다 10% 넘게 줄면 좋아짐, 10% 넘게 늘면 나빠짐.ITEM마다 개선 ÷ 기존 비, 그 중앙값이 0.9 미만 좋아짐, 1.1 초과 나빠짐, 사이 비슷 (TREND_BAND = 0.10). 지표: 측정 정밀도 %, σdie %, σrun %, 90% 구간 폭 %, 동등 아닌 ITEM 수.
전문나머지 용어 · 기관 · 기호 · 근거

통계 용어

LoD (검출한계)
0이 아니라고 말할 수 있는 가장 작은 크기. LoD = 3.29σ7. 열 LoD.
상대표준편차 (RSD)
흔들림 σ ÷ 값. 변동계수(CV)와 같은 뜻. LoQ 는 RSD 가 10% 가 되는 값.
부호검정
차이가 + 인 die와 − 인 die 수만 세어 중앙값을 따지는 방법. 90% 구간을 이것으로 구한다2.
MAD (중앙값 절대편차)
중앙값에서 떨어진 거리들의 중앙값. 튀는 값에 덜 흔들리는 퍼짐 크기. robust σ = 1.4826 × MAD8.
표준편차 (SD)
값이 평균 둘레로 퍼진 보통 크기.
자유도 (df)
t 값을 고를 때 쓰는 수. 회차 몫은 J − 1.
t-test (짝지은 t 검정)
차이의 평균이 0인지 보는 검정. 판정에 쓰지 않는 참고 값 (ttest, ttest_p)12.
F 검정
두 조건의 분산이 같은지 비로 보는 검정. 지금 도구는 쓰지 않음 (옛 판 용어).
Levene / Brown-Forsythe 검정
분산이 같은지 보는 검정. 지금 도구는 쓰지 않음 (옛 판 용어).
일치 상관계수 (CCC)
두 조건 값이 y = x 선에 얼마나 붙어 있는지. 지금 도구는 쓰지 않음 (옛 판 용어).
결정계수 (R²)
한 조건 값이 다른 조건 값의 변화를 얼마나 따라가는지. 지금 도구는 쓰지 않음 (옛 판 용어).

판정 세부

DOE 구간 (DOE 수준 구간)
DOE 값이 있을 만한 범위 = POR 중앙값 + 90% 구간. 2단계 LoQ 판정이 이 구간을 LoQ 와 견준다 (doe_center).
LoQ 판정 (2단계)
|POR 중앙값| < LoQ 인 ITEM. 이동이 ±Δ 안 → 동등. DOE 구간이 통째로 LoQ 이상이 아니면 → 동등 ('<LoQ 보고 일치'). 통째로 LoQ 이상이고 이동이 ±Δ 밖 → 차이, 걸침 → 미결.
바닥 근처 (LoQ 근처)
LoQ ≤ |POR 중앙값| < LoQ / (10 r), r = 5% 면 LoQ 의 1~2배. 1회 측정 잡음이 5% 몫보다 커서, 선형 TOST 길이면 Δ' = max(Δ, 장비 정확도 폭) 으로 본다 (cls_level 바닥 근처, status 'LoQ 근처').
log 판정 (verdict_log)
같은 TOST 를 L = log10|값| 에서 한 번 더 한 것. 판정 길 log TOST 의 3단계. 열 verdict_log, log_reason, center_log, ci_low_log, ci_high_log.
log 판정 대상
POR·DOE 값에 0이 없고 부호가 하나인 ITEM. 0이 있거나 부호가 섞이면 verdict_log 는 판정 제외.
Δlog (log 허용폭)
Δlog = log10(1 + r) + sigma_rep_log. 회차 몫을 넣은 Δlog_run = log10(1 + r) + t·√(1 + 1/J)·σrun_log 은 참고 열 verdict_final_log_run 에만 (결정 대기, 부록).
sigma_rep_log
die마다 L 회차값의 표준편차를 구한 뒤 그 die 중앙값. Δlog 의 회차 항.
sigma_die_log
L 에서 구한 σdie. 분석용, 판정에 안 씀.
sigma_run_log
L 에서 구한 σrun. 분석용, Δlog 에 안 들어감.
log 진단 대상
Fail 근거 도구가 log 진단 그림을 그리는 ITEM: 작을수록·클수록 흔들림이 있거나 verdict 와 verdict_log 가 다른 ITEM.
noise_slope · spread_robust
die별 log(회차 표준편차) 를 log(회차 평균) 에 맞춘 기울기. 0 근처면 잡음 일정, 1 근처면 잡음이 값에 비례. spread_robust ≥ 0.3 이고 기울기 ≥ 0.7 이면 cls_scale log.
정규화 변화량
판정 지도 가로축. 구간 가운데 ÷ 허용폭. ±1 이면 허용폭만큼 변함.
정규화 불확실성
판정 지도 세로축. 구간 반폭 ÷ 허용폭. 1 이상이면 동등이 될 수 없음 (해상도 부족).

데이터 상태 (status, 판정과 별개)

산포 0
σdie = 0 이거나 같은 값 die 가 50% 넘음 (fixed_share). 정량 구간이고 값 간격이 Δ 에 비해 거칠 때만 판정 제외.
회차 흔들림
die별 POR 회차 범위의 중앙값 ≥ Δ (run_jitter_over_delta ≥ 1).
조건 불안정
POR 회차끼리 값이 옮겨 감: 회차 차 gap ≥ Δ 이고 ≥ 3 × 표준오차 (por_gap_over_delta, por_gap_over_noise). die 잡음만으로는 붙지 않음.
작을수록 흔들림
값이 작은 die 일수록 회차 흔들림(log 범위)이 큼: ρ ≤ −0.5, 유효 die ≥ 10 (spearman_size_jitter).
클수록 흔들림
값이 큰 die 일수록 회차 흔들림이 큼: ρ ≥ +0.5, 유효 die ≥ 10.
상태 지표 열 (8개)
status 를 정할 때 쓴 값: por_gap_over_delta, por_gap_over_noise, run_jitter_pct, run_jitter_over_delta, spearman_size_jitter, resolution_step, resolution_over_delta (≥ 0.1 이면 분해능 부족), fixed_share.
분포 모양 열 (5개)
die별 POR 회차 평균 R 의 모양: decades, skew_lin, skew_log, log_fit, bimodality_log. |R| ≥ 1E+90 (Open 코드) die 는 뺌.
decades
값이 몇 자릿수에 걸쳐 있나: log10(P99|R| ÷ P1|R|).
skew_lin · skew_log
Bowley 사분위 왜도 (Q3 + Q1 − 2·Q2) ÷ (Q3 − Q1), −1~1. R 과 log10|R| 각각.
log_fit
log 를 취하면 더 대칭이 되나: |skew_lin| − |skew_log|. 양수면 log 쪽이 더 대칭.
bimodality_log
log10|R| 의 bimodality coefficient. 균일분포가 5/9.
log 후보
decades ≥ 1 이고 log_fit > 0.1. 표시만 하고 판정 길은 cls_scale 이 정한다.
두 덩어리
bimodality_log > 5/9 이고 die ≥ 10.
