t 값과 √(1+1/J)

기준 조건 J회 평균에서 새 1회 값이 얼마나 벗어날 수 있는지 정하는 배수. 계수 = t × √(1+1/J)

왜 쓰나

기준 조건 회차가 적을 때 흔들림을 작게 잡는 실수를 막음

자세히
  • t: σrun을 회차 J개로만 추정해 불확실함 → 1.645보다 큰 t를 씀. J가 작을수록 t가 큼
  • √(1+1/J): 새 1회 값의 흔들림(1)과 J회 평균의 흔들림(1/J)을 더함
  • J를 늘리면 계수가 줄어듦 → ⓪에서 J를 고르는 기준

그림

J = 2에서 7.73, J = 3에서 3.37로 크게 줄고, 그 뒤로는 조금씩 줄어듦

자세히

예시 숫자

J = 3이면 계수 3.37, σrun 0.5면 흔들림 여유 1.686

자세히
J = 3: t = 2.920, √(1+1/3) = 1.155 → 계수 3.37 / 3.3717 × σrun 0.5 = 1.686

합성 예시이며 실행 결과가 아닙니다.
