회차 예측 한계 계수 t·√(1+1/J)

이 쪽이 답하는 질문

기준 조건(Reference)을 J회 잰 평균과 다음 회차 하나는 얼마까지 어긋날 수 있나 · J 3에서 계수 3.3717은 어떻게 나오고 J를 늘리면 어떻게 바뀌나

쉬운 말로

  • 기준 조건을 J회 재서 평균을 기준으로 씀. 기준 조건을 한 번 더 재기만 해도 회차(run)마다 전체가 함께 움직여 그 평균과 어긋남
  • 이 어긋남의 위쪽 한계 = 회차 예측 한계 = 계수 × σrun. 이보다 작은 차이는 '차이'로 부르지 않게 Δ에 넣음1
  • t: σrun을 회차 J개만으로 추정해 불확실함
    • → J가 아주 클 때의 값 1.6449보다 큰 t를 씀. J 3이면 자유도(df, degrees of freedom) 2, t 2.919986 1.6449 = 정규분포 한쪽 95% 값 z0.95, 2 = J − 11
  • √(1+1/J): 새 회차 하나의 흔들림(1)과 J회 평균의 흔들림(1/J)을 합친 배율. J 3이면 1.154701 √(1+1/3) 내부 기준(문헌 근거 없음)
  • 계수 = t × √(1+1/J). J 3이면 3.3717, J 2면 7.7327, J 4면 2.6311 예시 계산 2줄과 J별 표
  • J를 늘리면 계수가 줄어 Δ가 좁아짐. 다만 J 3
    • → 4에서 줄어드는 폭이 J 2
    • → 3보다 훨씬 작음
    • → J는 ⓪에서 고름2
보충
  • ⓪ J 고르기: 회차 예측 한계가 실용 한계 5%를 넘지 않게 σrun/|기준 조건 중앙값| ≤ 5% / 계수. J 3이면 1.483%, J 4면 1.900%, J 5면 2.141% 예시 계산의 J별 표 내부 기준(문헌 근거 없음)
  • Δ 전체 식과 실용 한계는 허용 범위 Δ

그림

여기서 볼 것 · J 2 → 3에서 계수가 7.73 → 3.37로 절반 넘게 줄고, J 4 이후는 2.63 → 1.92로 조금씩만 줄어듦. 회차를 한두 번 더 재는 값어치는 J가 작을 때 큼

예시 계산

예시 데이터: 합성 예시 die 6개 표

  1. J = 3 → t의 자유도 J − 1 = 2 기준 조건 3회 + 비교 조건 1회로 잰 합성 예시 측정 항목(ITEM)
  2. 3.3717 = t(0.95, 2) 2.919986 × √(1+1/3) 1.154701
  3. 회차 예측 한계 = 3.3717 × σrun 0.50389 = 1.69896 0.50389 = ② 흔들림 구하기의 σrun
  4. Δ = 실용 한계 5.0 + 1.69896 = 6.69896 ≈ 6.699 5.0 = 5% × |100|, 100 = die 60개 전체 기준 평균의 중앙값
  5. ⓪ J 3의 허용 비율 = 5% / 3.3717 = 1.483% 내부 기준(문헌 근거 없음)
  6. 예시 비율 σrun/|중앙값| = 0.50389 / 100 = 0.5039% ≤ 1.483% → J 3로 충분
