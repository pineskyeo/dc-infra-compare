⓪ 표본 크기 정하기

이 쪽이 답하는 질문

die 60개로 충분한가 · 기준 조건(Reference)을 몇 번 다시 재야 '같다'를 가려낼 수 있나

쉬운 말로

  • ⓪은 측정 전에 두 가지를 정함: 기준 조건을 몇 번 다시 잴지(J), 가진 die 수로 차이를 가려낼 수 있는지
  • J: 기준 조건을 다시 재기만 해도 생기는 차이(회차 예측 한계)가 실용 한계(|기준 조건 중앙값|의 5%)를 넘지 않게 고름. 회차(run)마다 전체 값이 함께 움직이는 폭(σrun)이 클수록 J를 늘림
  • die 수: wafer당 die가 정해져 있어 새로 정하지 않음. 대신 이 die 수로 가려낼 수 있는 최소 여유를 계산해 확인
  • 여유 = Δ − |b|: 허용 범위 Δ에서 편향 b(비교 조건(Candidate)이 기준 조건보다 치우친 크기)를 뺀 남은 폭. 이 폭이 최소 여유보다 작으면 실제로 같아도 미결이 나오기 쉬움
  • 합성 예시 측정 항목(ITEM)(J 3, die 60개): σrun이 중앙값의 0.5039%로 1.48% 이하
    • → J 3로 충분. 최소 여유 0.6067에 비해 Δ 6.699, b 0.786이라 여유가 훨씬 큼
    • → die 60개로 충분 예시 계산 6~8줄 · Δ는 ⑤, b는 ④에서 구한 값
보충
  • die 수를 바꾸면 최소 여유와 미결 확률이 어떻게 바뀌는지는 아래 그림 슬라이더로 확인

수식

⇔ σrun/|기준 조건 중앙값| ≤ 5% / 계수, 계수 = t0.95, J−1·√(1+1/J)
(Δ−|b|)min ≈ 1.25·(z0.95+z0.95)·σdie·√(1+1/J)/√n
위 두 줄로 J를 고르고, 셋째 줄로 die n개가 가려낼 수 있는 가장 작은 여유를 구함. b는 예상 치우침(모르면 0)

기준 값 · J 고르기

σrun/|기준 조건 중앙값|으로 J를 고름: 1.48% 이하면 J = 3, 1.48~1.90%면 J = 4, 1.90~2.13%면 J = 55 내부 기준(문헌 근거 없음)

예외: 2.13%를 넘으면 반복을 늘리는 대신 프로브카드 접촉·측정 조건을 점검

J = 5는 비용 때문에 둔 상한 내부 기준(문헌 근거 없음). J를 더 늘리면 J = 6은 2.30%, J = 10은 2.60%까지 가능

유도: 위 표, 예시 계산 1~5줄

기준 값 · die 수

wafer당 die가 제한적이므로 die 수를 정하는 대신, 주어진 die 수로 판별 가능한 최소 여유를 확인. 유효 die는 최소 10개 · 최소 die 수(MIN_DIE)5 내부 기준(문헌 근거 없음)

예외: 유효 die가 10개 미만이면 미결

통과 조건

  • 회차 예측 한계가 |기준 조건 중앙값|의 5% 이하가 되는 가장 작은 J
  • Δ − |b| ≥ (Δ − |b|)min
  • 유효 die 최소 10개

읽는 법: Δ − |b|가 (Δ − |b|)min보다 작으면 실제로 같아도 미결이 나오기 쉬움. 부족하면 wafer 2장 이상 또는 J 증가 검토

die 60개, J = 3이면 판별 가능한 최소 여유 (Δ − |b|)min ≈ 1.25 × (1.645 + 1.645) × √(1+1/3) / √60 × σdie ≈ 0.61·σdie1

그림

여기서 볼 것 · die가 줄면 최소 여유가 커지고(60개 0.6067 → 10개 1.4860) 미결도 늘어남(17.4% → 53.2%). 60개에서 120개로 늘려도 미결은 17.4%에서 11.9%로 조금만 줄어듦
