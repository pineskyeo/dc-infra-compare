③ LoQ와 ITEM 유형

LoQ = 10σ를 구하고, POR 값만 보고 ITEM 유형과 판정 길을 정한다.

  • LoQ = 10σ: 1회 측정값을 숫자로 믿을 수 있는 가장 작은 크기.
  • POR 중앙값이 LoQ보다 작으면 값은 '<LoQ'로 보고하고, ⑥ 2단계에서 따로 판정한다.
  • POR 값만 보고 ITEM 유형을 나눈다. DOE 값은 보지 않는다.
  • 유형마다 판정 길이 하나 정해지고, ⑥ 3단계에서 쓴다.

  1. 확인 분해능 항 Δx/√12JCGM 100:2008 (GUM) 원문

  2. 확인 LoQ = 10σ, LoD = 3.29σEurachem Guide "Fitness for Purpose of Analytical Methods" 2판 (2014) · 6.2.4 Estimating LOQ, Quick Reference 3
    Eurachem (같은 문서) · Annex B Statistical basis of limit of detection calculations
    ICH Q2(R2) (2023) · 3.2.3.3 Based on the Standard Deviation of a Linear Response and a Slope (QL = 10σ/S)
    ICH Q2(R1) · 7.3 (QL = 10σ/S), 7.2 (S/N 10:1)
    EPA MARLAP Manual Vol. III · 20.2.7, 20.4.3 Minimum Quantifiable Concentration    2차 문헌으로. Currie 1968·IUPAC 1995 원문은 미열람(4절). NIST e-Handbook에서는 LoQ 10σ 항목을 찾지 못함. σ = max(4개 후보) 구성은 내부 설계대조표 #5
  3. 부분 blank 항 σ_blank, LoQ_blank = |평균| + 10·SDICH Q2(R2) · 3.2.3.3 "Based on the Standard Deviation of the Blank"
    ICH Q2(R1) · 7.3.1 Based on Standard Deviation of the Blank
    Eurachem 2014 · Quick Reference 2 NOTES 3, Quick Reference 3    blank SD로 σ를 잡는 것은 확인. "|평균| + 10·SD"는 Eurachem의 신호 영역 LOD 식(평균 + 3s)을 LoQ로 옮긴 내부 확장. CALCVAL 환산 조건은 내부 규칙대조표 #6
