③ 정량한계(LoQ)로 구간 나누기

이 쪽이 답하는 질문

값이 충분히 커서 숫자로 비교해도 되나(정량), 아니면 너무 작아 '정량한계(LoQ, Limit of Quantitation) 미만'으로 보고해야 하나

쉬운 말로

  • LoQ: 1회 측정값을 숫자로 믿을 수 있는 가장 작은 크기. LoQ = 10 × σ1
  • σ = 세 후보 중 가장 큰 값: 반복성 σdie(②) · 데이터 분해능 ÷ √12 · 장비 분해능 ÷ √12
  • blank: blank로 구한 LoQ가 위 LoQ보다 크면 blank LoQ로 바꿈
  • LoQ의 근거 항목(결과 표의 'LoQ를 정한 쪽')은 허용 범위 Δ의 출처가 아니라 LoQ를 정한 σ의 출처: 반복성 σdie · 데이터 분해능 ÷ √12 · 장비 분해능 ÷ √12 중 가장 큰 값, blank를 넣고 blank로 구한 LoQ가 더 크면 blank 예시: σdie 0.98965 > 데이터 분해능 0.001 ÷ √12 = 0.000289 → 기준 조건 반복
  • 분해능 항이 있는 이유: 값이 계단처럼 끊겨 3회가 모두 같으면 σdie = 0이 되어 LoQ도 0이 됨 → 이를 막음3
  • 비교 대상: 기준 조건(Reference) 중앙값(die별 J회 평균의 중앙값). |중앙값| ≥ LoQ → 정량, 작으면 LoQ 미만

더 자세한 쉬운 말은 아래 쉬운 말 더 보기

보충
  • √12: 분해능 Δx로 반올림될 때 반올림 오차의 표준편차 = Δx/√123
  • 장비 분해능: 측정 항목(ITEM) 정보의 측정 범위·CALCVAL로 정함4
  • blank: 원측정값이라 CALCVAL로 ITEM 단위로 바꿀 수 있을 때만 씀. LoQblank = |평균| + 10·표준편차(SD, Standard Deviation)2
  • 그림으로 보기: 정량한계(LoQ) · 분해능 Δx/√12

수식

σ = max( σdie, Δx데이터/√12, Δx장비/√12 )
LoD = 3.29·σ
LoQ = 10·σ
blank: LoQblank > LoQ면 LoQ = LoQblank, LoD = max(LoD, LoDblank)
|기준 조건 중앙값| ≥ LoQ → 정량 · 그 밖 → LoQ 미만
LoQ = 1회 측정의 상대표준편차가 10%가 되는 크기 · Δx = 분해능(값 사이 가장 작은 간격)
기호뜻예시 값
σLoQ·LoD를 정하는 흔들림. 세 후보 중 가장 큰 값0.98965 (σdie)
σdie반복성. 같은 die를 다시 잴 때 흔들리는 크기 (②)0.98965
Δx데이터데이터 값 사이 가장 작은 간격0.001
Δx장비장비 분해능. ITEM 정보가 있을 때만합성 예시에 없음

이 단계의 기준

판정 없음 · 계산 단계. LoQ로 구간만 정함

⑥에서 DOE 수준 구간(기준 조건 중앙값 + ④의 CI)을 LoQ와 견줌 → LoQ 아래 판정

갈래

갈래구간 이름조건다음
정량정량|기준 조건 중앙값| ≥ LoQ④ b·CI → ⑤ Δ → ⑥ TOST
LoQ 미만검출~정량LoD ≤ |기준 조건 중앙값| < LoQ④ CI · ⑤ Δ → ⑥ LoQ 판정
LoQ 미만검출한계 이하|기준 조건 중앙값| < LoD위와 같음 (LoD는 구간 이름만 나눔)

다음 단계로 넘기는 것

  • 기준 조건 중앙값(die별 J회 평균의 중앙값) → ⑤ 실용 한계 · ⑥
  • LoQ · LoD와 그것을 정한 쪽(기준 조건 반복 / 데이터 분해능 / 장비 분해능 / blank) → ⑥ 판정
  • blank 관련 값, 장비 사양 관련 값(⑤와 같음) → 결과 읽는 법

그림

여기서 볼 것 · σdie가 커지면 LoQ 막대가 중앙값 100 선으로 다가감 · σdie 8에서도 LoQ 80 < 100 → 정량 · LoQ 막대가 100 선을 넘으면 LoQ 미만 갈래로 감

쉬운 말 더 보기

  • 정량
    • → ④ 편향·90% 신뢰구간(CI, Confidence Interval)
    • → ⑤ Δ
    • → ⑥ 두 번의 한쪽 검정(TOST, Two One-Sided Tests)으로 판정
  • LoQ 미만
    • → ④의 CI와 ⑤의 Δ를 그대로 쓰고, ⑥에서 LoQ 판정(DOE 수준 구간이 LoQ 아래거나 걸치면 동등 · 통째로 위면 차이). 측정값은 그대로 기록하고 '<LoQ' 표시를 붙임 내부 기준(문헌 근거 없음)
  • 검출한계(LoD, Limit of Detection) = 3.29 × σ. LoQ 미만 안에서 구간 이름만 나눔
  • ⑥ 3단계의 ITEM 유형 '수준' 축도 LoQ로 나눔(기준 조건 값만으로 구한 LoQ): 0 중심(부호 섞임 + LoQ 아래) · 바닥 아래 · 바닥 근처(LoQ ~ 2·LoQ, r 5%) · 정량 → 분류 축
