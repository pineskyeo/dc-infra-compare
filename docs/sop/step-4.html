판정 기준

이 단계는 판정하지 않고, ±Δ를 ⑤·⑥에 넘깁니다.

자세히
C4-1판정 없음 · 계산 단계

±Δ → ⑤ 90% CI ⊂ (−Δ, +Δ) · ⑥ CI가 통째로 ±Δ 밖

수식

실용 한계와 회차 예측 한계의 합입니다.

자세히
Δ = r·|Ref 중앙값| + t0.95, J−1·√(1 + 1/J)·σrun
실용 한계 (r = 5%) + 회차 예측 한계: 기준 조건을 다시 재도 1회 측정값이 기준 조건 J회 평균에서 벗어날 수 있는 폭 (90% 예측구간 한쪽)
J = 3 → t0.95,2 = 2.920, √(1+1/3) = 1.155 → 배수 3.37
A·V ITEM (item_info): Δ = max(Δ, 장비 정확도 한계), 장비 정확도 한계 = 1.645·√((URef2 + UCand2)/3), U = a·|값| + b·range + c
