σdie와 σrun

이 쪽이 답하는 질문

같은 die를 다시 잴 때의 흔들림과 회차마다 전체가 함께 움직이는 크기를 왜 나누고, 각각 어떻게 구하나

쉬운 말로

  • σdie(반복성) = 같은 die를 다시 잴 때 die마다 따로 흔들리는 크기
  • σrun(회차 이동) = 측정 회차마다 모든 die가 함께 움직이는 크기
  • σdie: die를 많이 모으면 서로 상쇄됨
    • → 표본 크기(⓪)와 정량한계(LoQ, Limit of Quantitation)(③)에 씀 내부 기준(문헌 근거 없음)
  • σrun: 모든 die가 함께 움직여 die를 늘려도 줄지 않음 → 허용 범위 Δ의 회차 예측 한계(⑤)에 씀 내부 기준(문헌 근거 없음)
  • 둘을 하나로 합치면 die 수를 늘린 효과를 잘못 계산함
  • 둘 다 측정 항목(ITEM)당 1개: die마다 값 3개로는 σ를 믿을 수 없음
    • → 모든 die를 모아 하나로 추정 3 = 기준 조건 반복 회차 수 J
보충
  • die 사이 퍼짐(die마다 다른 고정 수준)은 σdie도 σrun도 아님. 기준 조건과 비교 조건에 똑같이 들어가 die별 차이 d에서 빠짐 내부 기준(문헌 근거 없음)
  • σ와 MAD의 관계는 표준편차 σ와 MAD, 중앙값이 평균보다 덜 효율적인 정도(π/2)는 중앙값 효율 1.25

수식

eij = xij − (die i의 회차 평균), rj = mediani(eij)
σrun = √max(0, Var(rj) − (π/2)·σdie²/n)
σdie = 이웃 회차 차이의 퍼짐. σrun = 회차 중앙값의 퍼짐에서 die 잡음 몫을 뺀 것

    • → ITEM당 1개123
  2. σrun: die마다 회차 평균을 뺀 값 eij의 회차별 중앙값 rj → rj의 분산에서 die 잡음 몫을 뺌5678
  3. die 잡음 몫: 회차 이동이 0이어도 회차 중앙값 rj는 die 잡음 때문에 움직임. 평균이면 분산 σdie²/n, 중앙값은 그 π/2배9 · 중앙값 효율 1.25
  4. 뺀 값이 0보다 작으면 σrun = 0 (식의 max)

그림

모형: 예시 ITEM을 만든 값 σdie 1.0 · σrun 0.5 (도구 추정 0.990 · 0.504)

σdie 1.0의 근거

  • 그림의 σdie 1.0 · σrun 0.5 = 예시 ITEM을 만든 값 합성 예시를 만들 때 넣은 반복 흔들림 1.0, 회차 이동 −0.5 / 0 / +0.5
  • 회차 이동 −0.5, 0, +0.5의 표준편차 = 0.5 = σrun
  • 도구가 그 예시 데이터에서 거꾸로 추정한 값 = σdie 0.990 · σrun 0.504 아래 예시 계산의 0.98965, 0.50389
  • 만든 값과 추정 값이 조금 다른 것은 die 60개, 회차 3번으로 추정하기 때문 내부 기준(문헌 근거 없음)

두 회차를 마주 놓고 보기

여기서 볼 것 · 왼쪽은 점이 대각선 둘레로 둥글게 퍼짐(σdie 큼), 오른쪽은 점 구름이 대각선과 평행하게 통째로 옮겨짐(σrun 큼)

측정 정밀도

질문

σdie와 σrun을 합쳐 측정 하나의 정밀도를 어떻게 한 숫자로 나타내나

쉬운 말로

  • 두 산포를 제곱해 더하고 루트를 씀
    • → 서로 독립인 산포는 분산이 더해짐. 표준편차를 단순히 더하면 과대평가
    • → 예: 3과 4 → √(3² + 4²) = 5 (단순 합 7 아님)11
  • 표준 표기: 정밀도는 산포(표준편차(SD, Standard Deviation) 또는 상대표준편차(RSD, Relative Standard Deviation))로 적음1213
  • 값이 클수록 정밀도가 나쁨. 100 − x로 바꾸지 않음13
  • 회차(run)가 다른 조건의 흔들림을 σrun으로 보는 것은 VIM(International Vocabulary of Metrology)의 중간 정밀도(intermediate precision) 조건에 대응시킨 이 문서의 해석임 이 문서의 해석1214

수식

σmeas = √(σdie² + σrun²)
측정 정밀도(%) = 100 × σmeas / |POR 중앙값| (중앙값 0이면 빈칸)
σmeas/Δ = 미결 원인을 볼 때 쓰는 보조 열

  1. σdie² = 0.98965² = 0.979407, σrun² = 0.50389² = 0.253905 위 예시 계산의 σdie, σrun
  2. σmeas = √(0.979407 + 0.253905) = √1.233312 = 1.11055
