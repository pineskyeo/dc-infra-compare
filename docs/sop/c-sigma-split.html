σdie와 σrun

σdie = 같은 die를 다시 잴 때 die마다 따로 흔들리는 크기. σrun = 측정 회차마다 모든 die가 같이 움직이는 크기

왜 쓰나

두 흔들림은 줄어드는 방식이 달라 따로 다룸

자세히
  • σdie: die를 많이 모으면 서로 상쇄됨 → 표본 크기(⓪)와 LoQ(②)에 씀
  • σrun: 모든 die가 같이 움직여 die를 늘려도 줄지 않음 → 허용 범위 Δ의 회차 예측 한계(④)에 씀
  • 하나로 합쳐 보면 die 수를 늘린 효과를 잘못 계산함

그림

회차가 바뀌면 점 전체가 같이 움직이고(σrun), 그 안에서 점이 따로 흔들림(σdie)

자세히

세 회차 모두 · σdie 1.0 · σrun 0.5

예시 숫자

σdie 1.0, σrun 0.5, 기준 조건 3회

자세히
σdie = 1.0, σrun = 0.5, J = 3. 그림의 회차 이동 −0.5, 0, +0.5의 표준편차 = 0.5 = σrun

합성 예시이며 실행 결과가 아닙니다.
