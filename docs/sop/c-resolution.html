분해능과 √12

이 쪽이 답하는 질문

값이 계단처럼 찍히면 그 계단 때문에 생기는 흔들림은 얼마인가 · 데이터 분해능 몫은 왜 Δx/√12이고, 예시에서는 왜 σdie를 쓰나

쉬운 말로

  • 분해능 Δx: 값이 찍히는 가장 작은 간격. 합성 예시 측정 항목(ITEM)의 값은 소수 3자리
    • → Δx = 0.001 예시 데이터 표, 예: 96.104
  • 찍힌 값 하나 뒤의 실제 값은 계단 한 칸(폭 Δx) 안 어디든 같은 확률로 있을 수 있음
  • 폭 Δx 안에 고르게 퍼진 값의 표준편차(SD, Standard Deviation) = Δx/√121
  • 쓰는 이유: 같은 die를 기준 조건(Reference)에서 3회 재서 값이 모두 같게 찍히면 σdie = 0
    • → 정량한계(LoQ, Limit of Quantitation)도 0이 됨. 분해능 몫이 σ의 아래 한계가 되어 이런 경우를 막음2
  • ③ 정량한계(LoQ)로 구간 나누기에서 σ = 세 후보(σdie · 데이터 분해능 몫 · 장비 분해능 몫) 중 가장 큰 값 내부 기준(문헌 근거 없음)2
  • 예시: 0.000289 < σdie 0.98965 → σdie를 씀 예시 계산 2~4줄
보충
  • √12의 유래: 반폭 a = Δx/2 안에 고르게 퍼진 값의 분산 = a²/3 = Δx²/12 → 표준편차 Δx/√121
  • 장비가 내는 분해능(장비 분해능)도 같은 식 Δx/√12로 σ 후보가 됨. 나머지 후보는 ③ 정량한계(LoQ)로 구간 나누기
  • 기호 Δx는 분해능. 동등 한계 Δ와 다른 기호

수식

u = Δx / √12
σ = max(σdie, Δx/√12, …)
u = 계단 한 칸 안에 고르게 퍼진 값의 표준편차 · σ = ③에서 LoQ 계산에 쓰는 흔들림, 세 후보 중 가장 큰 값
기호뜻예시 값
Δx분해능. 값이 찍히는 가장 작은 간격 (동등 한계 Δ와 다름)0.001
u분해능 몫. 반올림 때문에 생기는 흔들림의 표준편차0.000289
σdie반복성. 같은 die를 다시 잴 때의 흔들림0.98965

…그 밖의 후보(장비 분해능 등). ③ 쪽—

그림

여기서 볼 것 · 계단 한 칸 안에서 실제 값은 고르게 퍼짐 → 그 퍼짐의 표준편차가 Δx/√12 · 예시는 분해능 몫 0.000289가 σdie 0.98965보다 훨씬 작아 σdie를 씀2

예시 계산

예시 데이터: 합성 예시 die 6개 표

  1. Δx = 0.001 예시 데이터 값이 소수 3자리로 찍힘, 예: die 1 기준 1회 96.104
  2. 데이터 분해능 몫 = 0.001/√12 = 0.000289
  3. σdie = 0.98965 ② 흔들림 구하기 · 표준편차 σ와 MAD 예시
  4. 0.000289 < 0.98965 → 큰 쪽 σdie → σ = 0.98965
  5. 다음: LoQ = 10 × 0.98965 = 9.8965 LoQ와 10배
