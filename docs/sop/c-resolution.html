개념 익히기 · 4 / 11

분해능과 √12

분해능 Δx = 값이 찍히는 가장 작은 간격. Δx/√12 = 반올림 때문에 생기는 흔들림의 표준편차

왜 쓰나

값이 계단처럼 찍혀 3회가 같아도 흔들림을 0으로 보지 않게 함

자세히
  • 3회 값이 모두 같으면 σr = 0이 되어 LoQ도 0이 됨
  • 실제 값은 계단 한 칸(Δx) 안 어디든 같은 확률로 있을 수 있음 → 그 고른 분포의 표준편차가 Δx/√12
  • ② σ = max(σr, Δx/√12, …)의 후보로 씀

그림

계단 한 칸 안에서 실제 값은 어디든 고르게 있을 수 있음

자세히

예시 숫자

Δx = 0.1이면 흔들림 0.0289

자세히
Δx = 0.1 → 0.1/√12 = 0.2887 × 0.1 = 0.0289

합성 예시이며 실행 결과가 아닙니다.
