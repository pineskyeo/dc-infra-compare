① 반복성 확인

기준 조건 3회로 반복성 σr와 회차 간 정밀도 σrun을 구합니다.

판정 기준

이 단계는 판정하지 않고 계산만 합니다.

자세히
C1-1판정 없음 · 계산 단계

σr → ② LoQ로 구간 나누기 σ = max( σr, … )

σrun → ④ 동등 한계 정하기 t0.95, J−1·√(1 + 1/J)·σrun

수식

σr는 이웃 회차 차이에서, σrun은 회차 전체 이동에서 구합니다.

자세히
ek = (Yk+1 − Yk) − median(Yk+1 − Yk) 이웃 회차 차이, 회차 전체 이동은 뺌
σr = 1.4826 · median|e − median(e)| / √2 반복성. MAD 기반 robust 추정. √2 = 두 번 잰 차이 → 1회
rk = mediandie(Yk − Ȳdie) 회차 k의 전체 이동
σrun2 = Var(rk) − (π/2)·σr2/n 회차 간 정밀도. 반복성 몫을 뺌

통과 조건

σr와 σrun을 다음 단계로 넘깁니다.

자세히
C1-2

다음 단계로 넘기는 값

sigma_die · sigma_run 반복성 σr, 회차 간 정밀도 σrun

흔한 예외

이상치 die → robust(중앙값·MAD) 추정.

자세히
  • 이상치 die → robust(중앙값·MAD) 추정. 이상치 die에 끌려가지 않도록 합니다.

유도·설명

목적, 용어, 상수의 뜻입니다.

자세히

목적 · 기준 조건 3회만 씁니다. die마다 다른 값(공정 산포)을 빼고 남는 측정 정밀도를 두 성분으로 나눕니다. 이상치 die에 끌려가지 않도록 robust(중앙값·MAD)로 추정합니다.

  • 반복성 표준편차 repeatability SD σr: 같은 die를 다시 잰 1회 측정의 표준편차 (robust 추정)
  • 회차 간 정밀도 between-run precision σrun: 측정 회차마다 전체 값이 같이 움직이는 크기
  • 1.4826 = 정규분포에서 MAD를 σ로 바꾸는 상수
