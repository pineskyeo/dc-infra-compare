⓪~⑦ 단계의 식을 따라가려면 어떤 통계 개념을 어떤 순서로 익히나

쉬운 말로

  • 이 문서에 나오는 통계 용어를 읽는 순서대로 모음 · 1번부터 차례로 읽으면 ⓪~⑦ 단계의 식을 따라갈 수 있음
  • 쪽마다 뜻 · 쓰는 이유 · 그림 · 예시 숫자 · 출처
  • 다루는 약어: 중앙값 절대편차(MAD, Median Absolute Deviation) · 정량한계(LoQ, Limit of Quantitation) · 부호검정 · 신뢰구간(CI, Confidence Interval) · 두 번의 한쪽 검정(TOST, Two One-Sided Tests) · t-test(짝지은 t 검정)
  • 예시 숫자는 모두 합성 예시 측정 항목(ITEM) 하나: 기준 조건(Reference) 3회 + 비교 조건(Candidate) 1회, die 60개 · 합성 예시 die 6개 표

읽는 순서

  1. 중앙값과 평균
    중앙값 = 값을 크기순으로 놓았을 때 가운데 값. 평균 = 모두 더해 개수로 나눈 값 쓰는 단계 ④ ⑥
  2. 표준편차 σ와 MAD
    표준편차 σ = 값이 가운데에서 보통 얼마나 떨어져 있는지. MAD = 중앙값에서 떨어진 거리들의 중앙값 쓰는 단계 ②
  3. σdie와 σrun
    σdie = 같은 die를 다시 잴 때 die마다 따로 흔들리는 크기. σrun = 측정 회차마다 모든 die가 같이 움직이는 크기 쓰는 단계 ⓪ ② ⑤ 움직이는 그림
  4. 분해능과 √12
    분해능 Δx = 값이 찍히는 가장 작은 간격. Δx/√12 = 반올림 때문에 생기는 흔들림의 표준편차 쓰는 단계 ③
  5. LoQ와 10배
    LoQ = 1회 측정값을 숫자로 믿을 수 있는 가장 작은 크기. LoQ = 10·σ 쓰는 단계 ③ ⑥ 움직이는 그림
  6. 부호검정과 중앙값 90% 신뢰구간
    die별 차이 d를 크기순으로 놓고 앞뒤에서 같은 순번의 두 값을 고르면, 진짜 중앙값이 그 사이에 있을 확률이 90% 이상 쓰는 단계 ④ ⑥ 움직이는 그림
  7. 중앙값의 90% 신뢰구간은 어떻게 구하나
    진짜 중앙값보다 작은 die 수 = 동전 60번 던진 앞면 수
    • → 크기순 양끝에서 23개씩 떼면 남은 24번째~37번째가 90% 신뢰구간(실제 90.75%) 쓰는 단계 ④ 움직이는 그림
  8. t 값과 √(1+1/J)
    기준 조건 J회 평균에서 새 1회 값이 얼마나 벗어날 수 있는지 정하는 배수. 계수 = t × √(1+1/J) 쓰는 단계 ⓪ ⑤ 움직이는 그림
  9. 허용 범위 Δ
    편향이 이 안이면 같다고 보는 폭. Δ = |기준 조건 중앙값|의 5% + 회차 예측 한계 쓰는 단계 ⑤ ⑥
  10. TOST와 동등 · 차이 · 미결
    TOST = 한쪽 5% 검정 두 번. '편향 > −Δ'와 '편향 < +Δ'를 둘 다 보이면 동등. 90% 신뢰구간이 ±Δ 안에 드는 것과 같음 쓰는 단계 ⑥ 움직이는 그림
  11. 판정 지도는 왜 삼각형인가
    판정 지도의 점 = 90% 신뢰구간 하나. 가로 = 구간 가운데 ÷ Δ, 세로 = 반폭 ÷ Δ. 동등 |가로| + 세로 ≤ 1 → 삼각형 쓰는 단계 ⑥ 움직이는 그림
  12. LoQ 아래 판정
    기준 조건 중앙값이 LoQ 아래면 DOE 수준 구간(중앙값 + 이동 구간)이 LoQ 선 아래거나 걸치면 동등, 통째로 위면 차이 쓰는 단계 ⑥ 움직이는 그림
  13. ITEM 유형과 판정 길
    1·2단계에서 동등이 아닌 ITEM은 유형(부호 · 수준 · 분해능 · 모양 · 척도)에 맞는 판정 길 6개 중 하나로 다시 판정 쓰는 단계 ⑥ 움직이는 그림
  14. 0 근처와 절대 허용폭
    중앙값이 0으로 가면 5% 허용폭도 0으로 줄어 같은 이동도 차이가 됨 → 값 크기와 상관없는 고정 허용폭 쓰는 단계 ⑥ 움직이는 그림
  15. 잡음이 값에 비례하면 log
    die 값 대 반복 잡음의 기울기가 1 근처면 log, 0 근처면 linear · log 축에서는 비례 잡음 폭이 일정 쓰는 단계 ⑥ 움직이는 그림
  16. 중앙값 효율 1.25
    흩어짐이 정규분포일 때 중앙값의 흔들림은 평균의 약 1.25배(√(π/2)) 쓰는 단계 ⓪
  17. 검정력 90%와 표본 크기
    검정력 = 실제로 같을 때 '동등'으로 나올 확률. 표본 크기 = 그 확률에 필요한 die 수와 회차 수 J 쓰는 단계 ⓪
  18. t-test와 TOST
    t-test = 차이의 평균이 0인지 보는 검정. 마진이 0이라 '같다'를 증명하지 못하고, 기준 조건 회차끼리도 유의차를 자주 냄
    • → 판정에 안 쓰고 참고 지표로만 기록 쓰는 단계 ⑥
  19. 정밀도 비교(제안)
    기준 조건과 비교 조건의 흔들림(정밀도) 크기를 견주는 방법 · 제안 항목 내부 기준(문헌 근거 없음) 쓰는 단계 ②

  • 스크립트가 꺼져 있어도 그림의 기본 상태와 숫자 표는 그대로 보임
