C 원문 확인 필요

원문 안에서 표기나 전제가 서로 맞지 않는 다섯 곳입니다.

자세히
N1

원문 확인 필요 · N1 경계 포함 여부 · ⑤

⑤ 공식은 "90% CI ⊂ (−Δ, +Δ)", "H₁: −Δ < b < +Δ"(열린 구간)인데, 판정 표의 동등 조건은 "−Δ ≤ CI 아래, CI 위 ≤ +Δ"(닫힌 구간). CI 끝이 정확히 ±Δ일 때 판정이 문서 안에서 갈림.

N2

원문 확인 필요 · N2 절댓값 표기 · ⑥ · 판정 지도

⑥ 공식은 "|Cand 중심| ≥ LoQ"인데, 판정 흐름 d4와 판정 지도 머리글은 "Cand 중심 ≥ LoQ" / "Cand 중심 < LoQ"(절댓값 없음).

N3

원문 확인 필요 · N3 die 수 전제 · ③

"Binomial(61, 0.5)", "d(24), d(38)", "92.8%", "die 61개"는 die 61개 기준. 다른 die 수에서 순위가 어떻게 바뀌는지 원문에 설명이 없음.

N4

원문 확인 필요 · N4 원문 예시 반올림 · ⑥

원문의 실데이터 예시 하나에서 표시된 중심값이 "기준 조건 중앙값 + b" 표시값과 반올림이 맞지 않음. 실데이터 예시는 이 문서에서 뺐으므로 원문에서 확인.

N5

원문 확인 필요 · N5 표기 · ② · 판정 흐름

구간 표는 "|Ref| ≥ LoQ", 판정 흐름은 "|Ref 중앙값| ≥ LoQ". 같은 뜻으로 보이나 표기가 다름.
