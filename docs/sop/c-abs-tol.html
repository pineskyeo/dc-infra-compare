0 근처에서 %가 안 되는 이유와 절대 허용폭

이 쪽이 답하는 질문

값이 0 근처인 ITEM은 왜 '기준 조건의 5%' 허용폭으로 보면 안 되나 · 대신 쓰는 절대 허용폭은 무엇인가

쉬운 말로

  • Δ = 5% × |기준 조건 중앙값| + 회차 몫 · 앞쪽 5% 몫은 중앙값에 비례 허용 범위 Δ
  • 중앙값이 0으로 가면 5% 몫도 0 → Δ가 회차 몫만 남아 아주 좁아짐
  • 그래서 같은 이동인데 중앙값만 0에 가까워져도 동등 → 미결 → 차이로 바뀜
  • 절대 허용폭 = 값 크기와 상관없는 고정 폭 (ITEM 단위) · 중앙값이 어디 있든 그대로
  • 쓰는 ITEM: 0 중심(부호 섞임 + |중앙값| < LoQ) · 값이 계단인 정량·바닥 근처 ITEM ITEM 유형과 판정 길
