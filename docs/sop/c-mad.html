표준편차 σ와 MAD

표준편차 σ = 값이 가운데에서 보통 얼마나 떨어져 있는지. MAD = 중앙값에서 떨어진 거리들의 중앙값

왜 쓰나

튀는 die가 있어도 흔들림 크기를 바르게 잼

자세히
  • 표준편차는 튀는 값 하나에 크게 부풂
  • MAD에 1.4826을 곱하면 정규분포에서 σ와 같은 크기가 됨
  • ①의 σr(= σdie)을 이 방법으로 구함

그림

튀는 die 하나에 표준편차는 1.996 → 7.984, 1.4826·MAD는 2.002 그대로

자세히

예시 숫자

같은 die 60개에서 표준편차 1.996, 1.4826·MAD 2.002

자세히
die 60개: 표준편차 1.996, MAD 1.35 → 1.4826·MAD = 2.002 / die 하나를 160으로: 표준편차 7.984, MAD 1.35 그대로 → 2.002

합성 예시이며 실행 결과가 아닙니다.
