표준편차 σ와 MAD

이 쪽이 답하는 질문

튀는 값이 섞여도 흔들림 크기를 바르게 재려면 무엇을 쓰나 · σdie는 왜 표준편차(SD, Standard Deviation) 식이 아니라 중앙값 절대편차(MAD, Median Absolute Deviation) × 1.4826 ÷ √2로 구하나

쉬운 말로

  • 표준편차: 값이 평균 둘레로 퍼진 보통 크기. 평균에서 떨어진 거리를 제곱해 더하므로 크게 튀는 값 하나에 크게 부풂1
  • MAD: 중앙값에서 떨어진 거리들의 중앙값. 가운데 거리만 보므로 튀는 값 몇 개에 거의 안 움직임1
  • × 1.4826: 값이 정규분포를 따를 때 MAD를 표준편차와 같은 크기로 맞추는 배율1
  • ÷ √2: 같은 die를 두 번 잰 값의 차이는 1회 흔들림의 √2배로 커짐 → 나눠서 1회 흔들림으로 되돌림2
  • 결과 = σdie(반복성): 같은 die를 다시 잴 때의 흔들림. 합성 예시 측정 항목(ITEM)에서 0.98965 예시 계산 1~7줄
  • 예시 계산은 기준 조건(Reference) 3회 값만 씀. 비교 조건(Candidate) 1회 값은 쓰지 않음

더 자세한 쉬운 말은 아래 쉬운 말 더 보기

보충
  • 회차 쌍(2−1회, 3−2회)마다 차이의 중앙값(0.674, 0.586)을 먼저 뺌: 회차마다 모든 die가 함께 움직이는 몫(σrun)이 차이에 섞이지 않게 함 내부 기준(문헌 근거 없음) 예시 계산 3줄
    • → σdie와 σrun 나누기
  • 튀는 die를 빼지 않고 세기만 하는 이유 → 중앙값과 평균

수식

yik = xi,k+1 − xik (k = 1, …, J−1)
zik = yik − mk, mk = 중앙값i(yik)
MAD = 중앙값(|zik − 중앙값(z)|)
σdie = 1.4826 · MAD / √2
참고 · 표준편차 s = √( Σ(xi − x̄)² / (n − 1) )
이웃 회차 차이 → 회차 쌍별 중앙값을 뺌 → 가운데 거리(MAD) → 표준편차 크기로(× 1.4826) → 1회 흔들림으로(÷ √2)

yik이웃 회차 차이 (k+1회 − k회)die 1: 0.786, −0.425
mk회차 쌍 k마다 die 60개 차이의 중앙값0.674(2−1회), 0.586(3−2회)

√2두 번 잰 값의 차이가 1회 흔들림보다 커지는 배율—

그림

여기서 볼 것 · 강조 점 2.558 하나만 오른쪽으로 멀리 떨어짐. MAD는 가운데 거리만 보므로 이 값 하나에 끌려가지 않음 · 아래 막대: MAD 0.944 → × 1.4826 = 1.39957 → ÷ √2 = 0.989653
