중앙값 효율 1.25

흩어짐이 정규분포일 때 중앙값의 흔들림은 평균의 약 1.25배(√(π/2))

왜 쓰나

중앙값을 쓰는 대가로 die가 더 필요함을 표본 크기 식에 넣음

자세히
  • 중앙값은 튀는 die에 강하지만, 튀는 die가 없으면 평균보다 조금 더 흔들림
  • 같은 정밀도를 얻으려면 die가 π/2배 필요. 효율 = 2/π
  • ⓪ 최소 여유 식의 1.25가 이 값(근사값)

그림

같은 die 수에서 중앙값의 흔들림은 평균의 1.2533배, 필요한 die 수는 1.5708배

자세히

예시 숫자

√(π/2) = 1.2533, SOP 식에서는 1.25로 씀

자세히
√(π/2) = 1.2533, π/2 = 1.5708, 효율 2/π = 0.6366

합성 예시이며 실행 결과가 아닙니다.

출처
