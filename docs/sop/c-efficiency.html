중앙값 효율 1.25

이 쪽이 답하는 질문

⓪ 최소 여유 식 맨 앞의 1.25는 어디서 오나 · 평균 대신 중앙값을 쓰면 die가 얼마나 더 필요한가

쉬운 말로

  • ④에서 편향 b를 die별 차이 d의 평균이 아니라 중앙값으로 냄 → 튀는 die 몇 개에 끌려가지 않음 (부호검정과 중앙값 90% 신뢰구간)
  • 대가: 튀는 die가 없고 흩어짐이 정규분포 모양이면 중앙값이 평균보다 더 흔들림. 흔들림(표준편차(SD, Standard Deviation))이 √(π/2) = 1.2533배 중앙값 분산의 배율 π/2 = 1.5708의 제곱근12
  • 같은 정밀도를 얻으려면 die가 π/2 = 1.5708배 필요. 거꾸로 본 비 2/π를 중앙값 효율이라 부름1
  • ⓪ 최소 여유 식 맨 앞의 1.25 = 1.2533을 줄여 쓴 값 → 중앙값을 쓰는 몫을 die 수 계산에 미리 넣음3
  • 예시: die 60개, J 3이면 최소 여유 0.6067 예시 계산 3줄
보충
  • 같은 π/2가 ② 흔들림 구하기에도 나옴: 회차 중앙값에 섞인 die 잡음 몫 (π/2)·σdie²/n → σdie와 σrun 나누기
  • 흩어짐이 정규분포 모양이 아니면 1.2533배라는 값도 달라짐 내부 기준(문헌 근거 없음)
  • 최소 여유가 판정에서 어떻게 쓰이는지는 검정력 90%와 표본 크기

수식

평균의 분산 = σ²/n
중앙값의 분산 ≈ (π/2)·σ²/n → 흔들림 비 √(π/2) = 1.2533 ≈ 1.25
최소 여유 = 1.25 × (z0.95 + z0.95) × σdie × √(1+1/J) / √n
위 줄 = 중앙값이 평균보다 더 흔들리는 배율, 아래 줄 = 그 배율을 ⓪ 식 맨 앞에 곱함

그림

여기서 볼 것 · 중앙값은 흔들림이 1/4쯤 더 크고(1.2533), 그만큼 줄이려면 die가 절반쯤 더 필요(1.5708). ⓪ 식은 1.25를 곱해 이 몫을 미리 넣음

예시 계산

예시 데이터: 합성 예시 die 6개 표

  1. π/2 = 1.5708 중앙값의 분산 (π/2)·σ²/n의 배율
  2. √(π/2) = √1.5708 = 1.2533 → ⓪ 식에서는 1.25로 줄여 씀
  3. 최소 여유 = 1.25 × (1.6449 + 1.6449) × 0.98965 × 1.1547 / √60 = 0.6067 1.6449 = z0.95, 0.98965 = ② 흔들림 구하기의 σdie, 1.1547 = √(1+1/3), 60 = 합성 예시 측정 항목(ITEM)의 die 수
  4. 같은 식에 σdie 1.0을 넣으면 0.613 1.0 = 예시 ITEM을 만들 때 넣은 반복 흔들림
  5. 같은 π/2가 ②에서: die 잡음 몫 (π/2)·σdie²/n = 1.5708 × 0.98965² / 60 = 0.025641
