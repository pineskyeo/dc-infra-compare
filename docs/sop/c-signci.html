부호검정과 중앙값 90% 신뢰구간

이 쪽이 답하는 질문

편향 b 0.786은 얼마나 믿을 만한가 · die 60개에서 90% 신뢰구간(CI, Confidence Interval) [0.610, 1.102]는 왜 크기순 24번째와 37번째 값인가

쉬운 말로

  • d: die마다 비교 조건(Candidate) 값 − 기준 조건(Reference) J회 평균3. 편향 b = d 60개의 중앙값 0.786 예시 계산 1줄
  • 진짜 중앙값보다 작은 d의 개수는 동전을 60번 던져 앞면이 나온 수와 같은 꼴(한 번마다 절반 확률)
    • → 값의 크기를 몰라도 순번만으로 구간을 정할 수 있음. 이 생각이 부호검정1
  • d를 크기순으로 놓고 앞뒤에서 같은 순번의 두 값을 고르면, 진짜 중앙값이 그 사이에 있을 확률이 90% 이상. die 60개면 24번째와 37번째, 포함 확률 90.75% 예시 계산 2~4줄12
  • 구간 끝을 순번으로 고르므로 맨 끝에 튀는 die가 몇 개 있어도 구간 끝이 거의 안 움직임 내부 기준(문헌 근거 없음)
  • die가 많을수록 구간이 좁아짐 → 작은 편향도 가려냄. die 수별 순번은 예시 계산의 표
  • 이 구간을 ⑥ 판정에서 허용 범위 ±Δ와 견줌 → TOST와 동등 · 차이 · 미결
보충
  • 포함 확률이 딱 90%가 아닌 이유: 순번은 정수라 90% 이상이 되는 짝을 고름
    • → die 수마다 90.13% ~ 92.75% 예시 계산의 순번 표
  • 평균 대신 중앙값을 쓰는 대가는 중앙값 효율 1.25

수식

b = median(d1, …, dn)
90% CI = [d(k+1), d(n−k)]
k = P(B ≤ k) ≤ 5%인 가장 큰 수(양끝에서 떼는 개수), B ~ Binomial(n, 0.5)
포함 확률 = 1 − 2·P(B ≤ k)
d를 크기순으로 놓고 양끝에서 k개씩 떼어, 남은 처음과 끝 값을 구간 끝으로 씀. 양쪽 꼬리에서 5%씩 넘지 않게 뺌

그림

여기서 볼 것 · die 수를 늘리면 진한 점 묶음(90% 신뢰구간)이 좁아짐. 고르는 규칙(양쪽 꼬리 5% 이하)은 같고 순번만 바뀜

합성 예시 · 전체 데이터 examples/example_wide.csv

  1. b = d 60개의 중앙값 = 0.78583 ≈ 0.786 d = 비교 − 기준 3회 평균, die 60개 전체(위 표는 그중 6개). 측정 항목(ITEM) 하나 기준
  2. 떼는 개수 k = 23: Binomial(60, 0.5)에서 P(B ≤ 23) = 4.62% ≤ 5%→ 아래 끝 k + 1 = 24번째, 위 끝 n − k = 37번째 60 = die 수 n · 4.62% = 중앙값의 90% 신뢰구간 n = 60 표
  3. 위 끝 순번 = 60 + 1 − 24 = 37
  4. 포함 확률 = 1 − 2·P(B ≤ 23) = 90.75%
  5. 크기순 22~26번째 d: 0.5527, 0.5787, 0.61, 0.663, 0.7147 → 24번째 = 0.610
  6. 크기순 35~39번째 d: 1.0977, 1.1, 1.1023, 1.2107, 1.2143→ 37번째 = 1.10233 목록은 소수 4자리로 줄여 적음
  7. 90% CI = [0.610, 1.10233] ≈ [0.610, 1.102]
  8. 쓰는 곳: ⑥ 두 번의 한쪽 검정(TOST, Two One-Sided Tests)에서 [0.610, 1.102] ⊂ (−6.699, +6.699)→ 동등 6.699 = ⑤ 허용 범위 Δ
