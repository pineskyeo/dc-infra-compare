부호검정과 중앙값 90% 신뢰구간

die별 차이 d를 크기순으로 놓고 앞뒤에서 같은 순번의 두 값을 고르면, 진짜 중앙값이 그 사이에 있을 확률이 90% 이상

왜 쓰나

편향 b가 우연인지 die 수에 맞게 판단하게 함

자세히
  • 진짜 중앙값보다 작은 die 수는 동전 던지기와 같음 → 순번만으로 구간을 정함
  • 값의 크기를 쓰지 않아 튀는 die가 있어도 구간이 움직이지 않음
  • die가 많을수록 구간이 좁아져 작은 편향도 가려낼 수 있음

그림

die 수를 늘리면 같은 흩어짐에서도 90% 신뢰구간이 좁아짐

예시 숫자

die 60개면 크기순 24번째 ~ 37번째가 90% 신뢰구간

자세히
die 60개: P(B ≤ 23) = 4.62% ≤ 5% < P(B ≤ 24) = 7.75% → d(24) ~ d(37), 실제 포함 확률 90.75%
합성 d(편향 0.3, 흩어짐 1.0): 구간 [0.025, 0.575]

③ 본문은 원 자료대로 die 61개 기준(24번째 ~ 38번째, 92.8%)

합성 예시이며 실행 결과가 아닙니다.
