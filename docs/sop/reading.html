판정은 동등 · 차이 · 미결 세 가지이고, 미결은 해상도 부족과 경계로 나뉩니다.

판정조건뜻

차이CI 아래 > +Δ 또는 CI 위 < −Δ편향이 동등 한계보다 크다고 증명됨
미결 · 해상도 부족걸침, CI 반폭 ≥ Δb가 0이어도 ±Δ 안에 못 들어감. 정밀도 부족

미결은 CI 반폭 ≥ Δ면 해상도 부족, 아니면 경계입니다.

원문 확인 필요 · N2 ⑥ 공식은 "|Cand 중심| ≥ LoQ"인데, 판정 흐름 d4와 판정 지도 머리글은 "Cand 중심 ≥ LoQ" / "Cand 중심 < LoQ"(절댓값 없음).

원문 확인 필요 · N5 구간 표는 "|Ref| ≥ LoQ", 판정 흐름은 "|Ref 중앙값| ≥ LoQ". 같은 뜻으로 보이나 표기가 다름.

참고 지표 (판정에 쓰지 않음)

t-test는 기준 조건 회차끼리 비교해도 유의차를 자주 내므로 동등 판정에 쓰지 않습니다.

자세히

t-test (대응)

t = d̄ / (sd/√n), df = n − 1
H0: 평균 차이 = 0. 마진이 0이라 "같다"를 증명하지 못함
  • NIST/SEMATECH e-Handbook 7.3.1.1
