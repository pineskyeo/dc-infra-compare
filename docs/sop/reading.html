결과 읽는 법

이 쪽이 답하는 질문

결과 표 items.csv의 열은 무슨 뜻이고 어느 단계에서 나온 값인가 · 측정 항목(ITEM)마다 나온 동등 · 차이 · 미결을 어떻게 읽나

판정 읽는 법

  • 판정 대상 = 편향 b · die별 차이 d(비교 조건(Candidate) − 기준 조건(Reference) J회 평균)의 중앙값
  • b의 90% 신뢰구간(CI, Confidence Interval)이 허용 범위 ±Δ와 어떻게 놓이는지로 판정
  • 정량 구간은 두 번의 한쪽 검정(TOST, Two One-Sided Tests) → 동등 · 차이 · 미결 세 가지
  • 정량한계(LoQ, Limit of Quantitation) 미만 구간은 '<LoQ 보고 일치' → 동등 · 차이 두 가지
  • 동등 = 편향이 허용 범위 안이라고 증명됨 · 차이 = 허용 범위보다 크다고 증명됨 · 미결 = 어느 쪽도 증명 못 함 · 판정 제외 = 신뢰구간을 계산할 수 없거나, die 산포가 0(고정값 비율 > 50%)이거나, 정량 구간의 최종 Δ가 0 이하라 판정하지 않음
  • 차이나 미결이 나오면 ⑦ 미결·차이일 때 다음 행동

판정조건뜻

판정 제외①~③ 중 맞는 원인을 모두 순서대로 '; '로 이음('판정 제외: '는 첫 원인 앞에만, 예 '판정 제외: die 산포 0 (σ_die=0); 고정값 (중앙값 0·σ_run 0)'): ① 중심·CI NaN·inf ② die 산포 0(σdie = 0 또는 고정값 비율 > 50%) ③ POR 중앙값 0이고 σrun = 0 ④ 정량 구간에서 장비 정확도 대체 후 최종 Δ ≤ 0·NaN. LoQ 미만은 Δ와 무관하게 판정통계를 낼 수 없어 판정하지 않음 · 사유는 맞는 원인 모두 · 용어집

LoQ 미만 구간

차이 ⇔ [CI가 통째로 ±Δ 밖] AND [|비교 조건 중심| ≥ LoQ]
아니오 → 동등 <LoQ 보고 일치
  • 비교 조건 중심 = 기준 조건 중앙값 + b
  • 차이는 보고가 숫자로 바뀔 때만 · 그 밖은 둘 다 <LoQ 표시라 보고가 같음 → 동등4 내부 기준(문헌 근거 없음) · ⑥ 판정

데이터 상태 예시 계산

회차 흔들림 (Δ = 5)

  • die A 회차 10, 14, 6 → 범위 8, 평균 10 → 80%
  • die B 회차 20, 26, 14 → 범위 12, 평균 20 → 60%
  • die C 회차 5, 6, 4 → 범위 2, 평균 5 → 40%
  • run_jitter_pct = 중앙값(80, 60, 40) = 60%
  • 중앙값(범위) = 중앙값(8, 12, 2) = 8
  • run_jitter_over_delta = 8/5 = 1.6 ≥ 1 → 상태 '회차 흔들림'

작을수록 흔들림 (die 5개)

  • 회차 평균 1e-9, 1e-8, 1e-7, 1e-6, 1e-5 → x = −9, −8, −7, −6, −5
  • log 범위 y = 0.8, 0.5, 0.3, 0.2, 0.1
  • x 순위 1..5, y 순위 5..1 → ρ = −1.00 ≤ −0.5
  • 유효 die 5 < 10 → 상태는 붙이지 않고 spearman_size_jitter = −1.00만 기록 (같은 모양이 die 10개 이상이면 '작을수록 흔들림')

조건 불안정 (n = 25, sigma_die = 2, Δ = 1)

  • rr = 회차별 중앙값(값 − die별 회차 평균). die 사이 차이는 지워짐(짝지은 회차 차)
  • gap = max(rr) − min(rr)
  • se = 1.2533 × 2 × 1.414 / 5 = 0.709 → 3·se = 2.13
  • A: rr = (−0.6, +0.1, +0.5) → gap = 1.1 ≥ Δ, 하지만 < 2.13 → 상태 없음. por_gap_over_delta = 1.1, por_gap_over_noise = 1.55
  • B: rr = (−1.5, +0.2, +1.3) → gap = 2.8 ≥ Δ, ≥ 2.13 → 상태 '조건 불안정'. por_gap_over_delta = 2.8, por_gap_over_noise = 3.95
  • 예전 규칙(회차별 die 중앙값의 max − min ≥ Δ)은 die 잡음만으로도 붙음. 예제 데이터(make_por3_data.py)에서 3 ITEM → 새 규칙 0 ITEM. IOFF_FLOOR는 gap/Δ 21.9, gap/se 0.85 → die 잡음
