실행 방법

측정 파일을 모으고 도구를 돌리는 방법.

처음 한 번

  1. 설치Python 3.9 이상에서 한 번.
    pip install -r requirements.txt
  2. 측정 파일 모으기POR 회차마다 폴더 하나 (2회 이상, 보통 3회), DOE 폴더 하나.
    data/A/POR1  data/A/POR2  data/A/POR3
data/A/DOE
  3. combos.ini 쓰기combos.example.ini 를 복사해 조합 이름과 경로를 적는다.
    [A1]
por = data/A/POR1
      data/A/POR2
      data/A/POR3
doe = data/A/DOE
  4. 판정하고 리포트 열기끝나면 결과 폴더의 report.html 을 브라우저로 연다.
    python dcc.py judge A1
→ <out>/A1/report.html

자주 쓰는 명령 셋

python dcc.py judge A1판정하고 리포트를 만든다. 늘 이것부터.
python dcc.py item A1 ITEM이름차이·미결 ITEM 하나를 원데이터 그림으로 본다.
python dcc.py compare A1 --before 이전/items.csv예전 결과보다 좋아졌는지 본다.
  • A1 은 combos.ini 의 조합 이름입니다. 이름은 python dcc.py list 로 봅니다.
  • 결과를 읽는 순서는 결과 읽는 법.
전문모든 명령 · 설정 키 · 결과 폴더 · 도구 직접 실행

combos.ini 형식

[defaults] 밖의 섹션 하나가 조합 하나이고 섹션 이름이 조합 이름입니다. 조합에 적은 키가 [defaults] 보다 먼저입니다. 상대 경로는 설정 파일이 있는 폴더 기준입니다. 모르는 이름·키, POR 1회, 없는 경로는 아무것도 돌리기 전에 알려 주고 끝납니다 (rc=2). 설정 파일은 기본으로 현재 폴더의 combos.ini, 다른 파일은 모든 명령에 --config 파일.

[defaults] out = 결과 level = item_info.csv groups = groups.csv scales = scales.csv abs_tol = abs_tol.csv [A1] por = data/A/POR1 data/A/POR2 data/A/POR3 doe = data/A/DOE before = 이전결과/A1/items.csv
키뜻판정 도구 옵션
porPOR 회차 경로, 한 줄에 하나, 2회 이상 (필수)--por × J
doeDOE 1회 경로 (필수)--doe
levelITEM 정보 표 ITEM,LEVEL,CALCVAL,DERIVED. 장비 분해능·정확도와 blank 환산--level
blank, blank_mapblank 데이터(한 줄에 하나)와 ITEM,BLANK_ITEM 연결표. LoQ 하한으로만 씀--blank, --blank-map
key, encoding짝짓기 키 (기본 WAFERID,COORD_X_Y,ITEM), 글자 인코딩 (기본 auto: UTF-8, 안 되면 CP949)--key, --encoding
r허용폭의 5% 몫 비율. 기본 0.05--r
groupsITEM,group 파일. 그룹별 측정 안정도, group 명령, compare 범위--groups
scalesgroup,scale 파일 (log · linear · auto). ITEM 척도 cls_scale → 판정 길 log TOST · 선형 TOST. groups 필요--scales
abs_tolgroup,abs_delta 파일 (ITEM 단위). 판정 길 절대 허용폭의 폭. 없으면 기본값. groups 필요--abs-tol
before예전 결과 items.csv. compare · group · slides 의 비교 대상 (--before 가 먼저)–
out출력 폴더. 조합 결과는 <out>/<이름>/. 기본 dcc_out--out

명령하는 일옵션

judge 이름판정 → LoQ·log 재확인 (review/) → 판정 지도 → report.html. judge all 은 모든 조합 (하나가 실패해도 계속)--detail: 최종 판정이 차이·미결인 ITEM 모두 item 분석

group 이름그룹별 판정 지도. groups 필요--before: compare 와 같은 비교도

report 이름리포트만 다시 (report.html, item/, group/, compare/)--anon: 익명 ID만, report_anon.html
classes 이름ITEM 유형과 판정 길: 개수, 목록, 그림, 길마다 예시 ITEM (참고, 판정 불변)
slides 이름판정 기준 장표 2쪽 slides.pptx (ITEM은 익명 번호)--before: 예전 → 새 판정 개수

item, group, compare, classes 는 <out>/<이름>/items.csv 를 다시 쓰고, 없을 때만 judge 단계를 먼저 돌립니다. 단계마다 이름과 명령을 찍고, 실패하면 그 단계에서 멈추고 오류 끝 20줄을 보여 줍니다.

도구 직접 실행

dcc.py 가 안에서 부르는 판정 도구를 직접 돌려도 판정은 같습니다. 판정에서 요약·재확인·Fail 근거·판정 지도까지 한 번에 돌리려면 run_all.py.

python por_doe_compare.py --por POR1/ --por POR2/ --por POR3/ --doe DOE/ \ --level item_info.csv --groups groups.csv --scales scales.csv \ --abs-tol abs_tol.csv --out 결과 python summarize.py 결과/items.csv python run_all.py --por POR1/ --por POR2/ --por POR3/ --doe DOE/ \ --level item_info.csv --out 결과
  • UNIT, SPECLOW, SPECHIGH 열은 판정에 쓰지 않습니다. 판정은 비율 기준이라 단위나 정규화 계수와 무관합니다.
  • 환경변수 DC_JOBS: 그림을 나눠 그릴 프로세스 수 (기본 CPU 수). review.py --max-figures N: 재확인 그림 수 (기본 100, 0이면 전부).

합성 예제로 돌려 보기 (README 예제):

python examples/make_por3_data.py p3 python por_doe_compare.py --por p3/por_run1 --por p3/por_run2 --por p3/por_run3 \ --doe p3/doe --level p3/level.csv --blank p3/blank \ --blank-map p3/blank_map.csv --out p3/out

입력 파일 모양

ITEM,LEVEL,CALCVAL,DERIVED ← --level (item_info.csv) IOFF_N1,10fA,1e12,N 원측정값 10~100 fA, 파일 값 = 원측정값 × 1e12 VT_N1,,,Y 변형 값: 장비 사양과 blank를 안 씀 OPEN_I_1PA,OPEN_I_10PA,SHORT_V ← --blank (원측정값, 측정 순서대로) 1.2e-12,3.1e-12,0.00012 ITEM,group ← groups group,scale ← scales group,abs_delta ← abs_tol VT_N1,VT VT,linear IOFF,1e-12

코드 위치

  • 설정 키: dcc.py · KEYS, 명령: dcc.py · build_parser(), 명령마다 단계: dcc.py · MODES
  • abs_tol 파일 읽기: classify.py · read_abs_tol()
