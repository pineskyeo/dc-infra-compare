실행 방법

이 쪽이 답하는 질문

무엇을 재서 어떤 파일로 도구를 돌리고, 도구가 낸 값이 ⓪~⑦ 단계 중 어디에 해당하나

쉬운 말로

  • 같은 wafer의 같은 die를 기준 조건(Reference)으로 J회, 비교 조건(Candidate)으로 1회 측정 · J = 기준 조건 반복 회차 수(권장 3회) · 회차(run)마다 재터치다운
  • 측정 결과는 DCNORMAL 파일 · 도구가 측정 항목(ITEM)마다 정량한계(LoQ, Limit of Quantitation)로 구간을 나누고 동등 · 차이 · 미결로 판정
  • 순서: 측정 준비 → 설치 → dcc.py로 실행 → 결과 파일 · 판정 읽기는 결과 읽는 법
  • 보통은 dcc.py 하나로 실행 · 데이터 묶음을 combos.ini에 한 번 적고 이름으로 부름
  • README 옵션 이름: --por = 기준 조건 1회분, --doe = 비교 조건 1회분
  • 'README 인용' 표시 아래 칸은 도구 README 글자 그대로(옛 용어 포함)1

측정 준비

  • J와 die 수: ⓪ 표본 크기 정하기에서 정함 · J 3 · die 60개 합성 예시 설정
  • 회차별 측정 방법(매번 재터치다운): ① 반복 측정

README 인용

같은 웨이퍼, 같은 die를 POR(기존 프로그램)로 여러 번, DOE(새 프로그램)로 한 번 잰 DCNORMAL 결과를 ITEM별로 비교해서 동등 / 차이 / 미결로 판정합니다.

README 인용 · 기준 조건 회차 수 (옵션 설명)

POR 1회분 (파일이나 폴더). 회차마다 따로 씁니다. 2회 이상, 권장 3회 이상(매번 재터치다운)

옵션

README 인용

옵션내용
--porPOR 1회분 (파일이나 폴더). 회차마다 따로 씁니다. 2회 이상, 권장 3회 이상(매번 재터치다운)
--doeDOE 1회분
--r허용폭의 정책 몫. 기본 0.05 (POR 값의 5%)
--levelITEM 정보 표 (선택, 아래). 장비 분해능·정확도와 blank 환산에 씀
--blank, --blank-mapblank 데이터와 연결표 (선택, 아래). LoQ 하한으로만 씀
--key짝짓기 키. 기본 WAFERID,COORD_X_Y,ITEM
--encoding기본 auto (UTF-8, 안 되면 CP949)

UNIT, SPECLOW, SPECHIGH 열은 판정에 쓰지 않습니다(값이 잘못 들어간 경우가 많음). 판정은 모두 비율 기준이라 단위나 정규화 계수가 무엇이든 결과가 같습니다.

입력 파일

  • 필수: 기준 조건 회차별 DCNORMAL 결과(파일이나 폴더) J개 + 비교 조건 1개
  • 짝짓기 키(기본): WAFERID, COORD_X_Y, ITEM
  • 선택: ITEM 정보 표, blank
  • 아래 인용에 나오는 약어: CALCVAL · 전원·측정 장치(SMU, Source/Measure Unit) · GUM(Guide to the Expression of Uncertainty in Measurement)

ITEM 정보 표 (--level, 선택)

README 인용

ITEM,LEVEL,CALCVAL,DERIVED IOFF_N1,10fA,1e12,N ← 원측정값 10~100 fA, 파일 값 = 원측정값 × 1e12 (pA로 찍힘) ION_N1,100nA,,N ← CALCVAL 모름 VT_N1,,,Y ← 변형 값 (여러 측정 조합·추출: Vt 추출, 저항 = V / I, 비율 등)
열뜻
LEVEL원측정값 |값|의 자릿수 아래 끝. 10fA = 10~100 fA, 1nA = 1~10 nA. 1fA … 100mA, 1uV … 1V (A, V는 장비 사양 적용), fF, pF, kHz, MHz (기록만)
CALCVAL파일 값 = 원측정값 × CALCVAL (단위 환산, 정규화, 부호 포함). 모르면 비움
DERIVEDY = 변형 값. 장비 사양과 blank를 쓰지 않음 (LEVEL 비워도 됨)
경우장비 분해능·정확도blank
변형안 씀안 씀
변형 아님 + CALCVAL 있음원측정값 = 파일 값 / |CALCVAL|로 정확히 환산× |CALCVAL| 해서 씀
변형 아님 + CALCVAL 없음자릿수 상한 10L로 보수적 환산안 씀
  • 장비 사양: Keysight P9001A Per-pin SMU (P9001 Data sheet p.6-7, Programming Reference Table 2-19/2-22). auto range는 값이 들어가는 가장 작은 range입니다. 표는 por_doe_compare.py의 I_RANGES, V_RANGES. 원본과 대조해서 쓰세요.
  • 장비 정확도 허용폭: 두 측정이 각자 사양 정확도 ±(a × |값| + b × range + c) 안일 때 생길 수 있는 차이 1.645 × √((U_POR² + U_DOE²) / 3) (균일분포, GUM 4.3.7). 사양의 Vo, Rres × Io 항은 0으로 둡니다.
  • level_check: CALCVAL로 환산한 원측정값이 LEVEL 자릿수와 다르면 "불일치". 자릿수 경계는 1.15배까지 일치로 봅니다. CALCVAL이 맞으면 판정에는 영향이 없습니다.

blank (--blank, --blank-map, 선택)

README 인용

blank는 원측정값(A, V 기본 단위)이어야 합니다. 가로형 CSV가 가장 쉽습니다. 맨 윗줄에 blank 조건 이름을 쓰고, 그 아래에 측정값을 측정 순서대로 붙입니다.

OPEN_I_1PA,OPEN_I_10PA,SHORT_V 1.2e-12,3.1e-12,0.00012 -0.8e-12,-1.5e-12,-0.00008

제품 ITEM과 이름이 다르면 연결표를 만듭니다. 같은 측정 종류, 같은 range끼리 연결합니다.

ITEM,BLANK_ITEM IOFF_N1,OPEN_I_1PA VT_N1,SHORT_V

그 밖에 DCNORMAL blank 파일·폴더, CSV ITEM,VALUE, CSV ITEM,SIGMA0도 읽습니다. blank 측정 구성은 전류와 용량은 open, 전압은 short입니다. blank LoQ = |평균| + 10 × 표준편차를 CALCVAL로 ITEM 단위로 바꿔, POR 반복 LoQ보다 크면 그쪽을 씁니다(blank_status).
