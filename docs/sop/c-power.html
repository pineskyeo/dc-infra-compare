검정력 90%와 표본 크기

검정력 = 실제로 같을 때 '동등'으로 나올 확률. 표본 크기 = 그 확률에 필요한 die 수와 회차 수 J

왜 쓰나

실제로 같은데 die가 모자라 미결이 나오는 일을 미리 막음

자세히
  • die 수가 정해져 있으면 판별 가능한 최소 여유 (Δ−|b|)min을 먼저 계산
  • Δ−|b|가 이 값보다 작으면 실제로 같아도 미결이 나오기 쉬움 → wafer 2장 이상 또는 J 증가 검토
  • z0.95 두 개: 하나는 TOST 한쪽 5%, 하나는 검정력 90%. 예전 z0.90은 실제 검정력 80%

그림

die가 늘면 판별 가능한 최소 여유가 줄어듦(J = 3, σdie 단위)

자세히

예시 숫자

die 60개, J = 3이면 최소 여유 0.613·σdie

자세히
(Δ−|b|)min ≈ 1.25 × (1.645 + 1.645) × √(1+1/3) / √60 × σdie = 0.613·σdie
검정력: 예전 식 80.02%, 지금 식 90%

⓪ 본문은 ≈ 0.61·σdie로 표기

합성 예시이며 실행 결과가 아닙니다.
