정밀도 비교(제안)

내부 기준(문헌 근거 없음) 제안 쪽 · 판정(⑥)에 쓰지 않음 · 도구에 아직 없음

이 쪽이 답하는 질문

비교 조건(Candidate)이 기준 조건(Reference)보다 같은 조건을 다시 잴 때 덜 흔들리는지(정밀도)를 중심(편향) 판정과 따로 어떻게 보나

쉬운 말로

  • 정밀도 비교 = 같은 조건을 다시 잴 때 흔들림(반복성 σdie)이 줄었는지 보는 것. 중심(편향 b) 판정과 따로 봄 내부 기준(문헌 근거 없음)
  • 지금 판정(⑥ 판정)은 중심만 봄. 비교 조건의 흔들림이 줄어도 개선으로 드러나지 않음 내부 기준(문헌 근거 없음)
  • 예: 기준 조건이 불안정(같은 조건 두 회차(run)의 die 값이 잘 안 맞음, 그림 왼쪽 둥근 구름)하고 비교 조건이 안정(그림 오른쪽, 대각선에 붙음) 내부 기준(문헌 근거 없음)
  • 방법 1 · σdie 비: 비교 조건도 3회 이상 재서 ② 흔들림 구하기와 같은 방법으로 σdie를 구하고 두 조건을 나눔3 내부 기준(문헌 근거 없음)
  • 방법 2 · 분산 비교 검정: F 검정(두 분산의 비)1 또는 Levene / Brown-Forsythe 검정(중앙값 기준인 Brown-Forsythe는 정규분포가 아닌 자료에도 강건)2
  • 방법 3 · 같은 조건끼리 일치 상관계수(CCC, Concordance Correlation Coefficient)·결정계수(R²) 비교: 기준1–기준2 와 비교1–비교2 내부 기준(문헌 근거 없음)

더 자세한 쉬운 말은 아래 쉬운 말 더 보기

보충

큰 잡음 대응 순서 내부 기준(문헌 근거 없음)

  1. σrun과 σdie를 비교해 어느 쪽이 큰지 봄
  2. 측정 조건을 먼저 고침
  3. 회차 추가
  4. 그래도 미결이면 사람이 사유를 기록한 뒤 결정 (⑦ 미결·차이일 때 다음 행동)

수식

정밀도 비 = σdie(비교) / σdie(기준)
F = s²(기준) / s²(비교)
CCC = 2·s12 / (s1² + s2² + (m1 − m2)²)
비가 1보다 작거나 F가 1보다 크면 비교 조건이 덜 흔들림. 얼마나 달라야 '좋아짐'인지 정한 기준은 아직 없음(제안)
기호뜻예시 값
σdie(기준)기준 조건의 반복성. 같은 die를 다시 잴 때 흔들리는 크기0.98965 (따로 만든 예: 2)
σdie(비교)비교 조건의 반복성. 비교 조건을 3회 이상 재야 구함— (따로 만든 예: 1)
s²분산. 표준편차의 제곱—
F두 분산의 비1— (따로 만든 예: 4.0)
s12, s1², s2²두 회차 값의 공분산, 각 회차 값의 분산—
m1, m2두 회차 값의 평균. 통째 이동이 있으면 차이가 생김—
r, R²같은 die 두 값의 상관계수와 그 제곱(결정계수)— (따로 만든 예: r 0.692 / 0.900)

그림

여기서 볼 것 · 왼쪽(기준 조건끼리)은 점이 대각선 둘레로 둥글게 퍼짐(r 0.642), 오른쪽(비교 조건끼리)은 대각선에 더 붙음(r 0.859) · 두 판 모두 평균 차이가 거의 0(0.001, 0.0)이라 중심 판정으로는 이 차이가 안 보임

쉬운 말 더 보기

  • 기준–비교 R² 하나로는 못 봄: R²는 die 사이 퍼짐에 따라 바뀌고 회차 통째 이동을 못 봄 내부 기준(문헌 근거 없음)

예시 계산

예시 데이터: 합성 예시 die 6개 표

  1. 예시 측정 항목(ITEM): σdie(기준) = 0.98965 ② 흔들림 구하기: 1.4826 × MAD 0.944 = 1.39957, ÷ √2
  2. 예시 ITEM은 비교 조건을 1회만 재서 σdie(비교)를 구할 수 없음→ 정밀도 비교는 아래 따로 만든 합성 예시로 보임 기준 조건 3회(J = 3) + 비교 조건 1회
  3. 따로 만든 합성 예시: die 사이 퍼짐 3, σdie(기준) 2, σdie(비교) 1 정밀도 비교를 보이려 만든 값 · 실행 결과 아님
  4. 정밀도 비 = 1 / 2 = 0.5F = 2² / 1² = 4.0
  5. 같은 조건끼리: r(기준1, 기준2) 0.692 (R² 0.479)r(비교1, 비교2) 0.900 (R² 0.810) 같은 모형의 값
  6. 기준–비교 R² 0.623 · die 사이 퍼짐 3→ 1이면 R²(기준, 비교) 0.10→ 잡음은 같은데 R²만 바뀜 같은 모형의 값
  7. 회차 통째 이동 2를 넣으면: R²(기준1, 기준2) 0.479 그대로, CCC 0.692→ 0.600→ R²는 통째 이동을 못 봄 같은 모형의 값
  8. 두 줄 결론 예: 중심 동등 · 정밀도 좋아짐 내부 기준(문헌 근거 없음)
