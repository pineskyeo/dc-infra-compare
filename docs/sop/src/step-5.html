⑤ 허용 범위 Δ 정하기

이 쪽이 답하는 질문

비교 조건(Candidate)과 기준 조건(Reference)의 차이가 얼마 안이면 '같다'고 볼까 (허용 범위 Δ)

쉬운 말로

  • Δ = 실용 한계 + 회차 예측 한계. 차이가 ±Δ 안이면 같다고 봄
  • 실용 한계 = 5% × |기준 조건 중앙값|(die별 J회 평균의 중앙값). 5%라는 값 내부 기준(문헌 근거 없음)
  • 회차 예측 한계: 기준 조건을 다시 재도 1회 측정값이 기준 조건 J회 평균에서 벗어날 수 있는 폭(90% 예측구간 한쪽). 회차(run) 변동 σrun(②)으로 구함2
  • σrun을 회차 J개로만 추정하므로 1.645 대신 t를 씀. t의 자유도(df, degrees of freedom) = J − 1
  • 회차를 늘리면 계수가 1.645·√(1+1/J)에 가까워지고 Δ가 줄어듦 (아래 J별 계수 표)
  • Δ의 두 조각(실용 한계 5% × |기준 조건 중앙값|, 회차 예측 한계 계수 × σrun)은 Δ를 만드는 재료일 뿐. 허용 범위는 0을 가운데 둔 −Δ ~ +Δ 예시: 0.05 × 100 = 5.0, 3.3717 × 0.50389 = 1.69896 → Δ = 6.699 → 허용 범위 −6.699 ~ +6.699

더 자세한 쉬운 말은 아래 쉬운 말 더 보기

보충
  • 두 한계를 더하는 구성: '실무 허용 + 기준 조건 재측정 차이' 설계 원칙 내부 기준(문헌 근거 없음)
  • 장비 정확도 한계의 U = a·|값| + b·range + c: a·b·c는 장비 사양 계수(④의 편향 b와 다름)
  • 그림으로 보기: 허용 범위 Δ · 회차 예측 한계 계수

다음 단계로 넘기는 것

  • ±Δ → ⑥ 판정: 90% CI ⊂ (−Δ, +Δ) · CI가 통째로 ±Δ 밖 (정량 · LoQ 미만 두 갈래 모두)
  • Δ와 그 구성(실용 한계 + 회차 예측 한계) → 결과 읽는 법

A·V ITEM 관련 값

그림

여기서 볼 것 · J 2 → 3에서 Δ가 가장 크게 줄어듦(예시 ITEM 8.8964 → 6.6990) · J 10이면 5.9688로 실용 한계 5.0에 다가감 · 모의실험 Δ 중앙값(J 3: 6.409)이 예시 ITEM 6.6990보다 작은 것은 회차 3번으로 추정한 σrun이 매번 달라서 내부 기준(문헌 근거 없음)

쉬운 말 더 보기

  • A·V 측정 항목(ITEM)(ITEM 정보에 장비 사양이 있을 때): 바닥 근처(LoQ ≤ |기준 조건 중앙값| < LoQ/(10r))이고 ⑥ 3단계 판정 길이 선형 TOST면 장비 정확도 한계와 비교해 큰 쪽을 Δ'로 씀(verdict_basis accuracy). 1·2단계의 Δ는 그대로 · 예전 옵션 판정(log 후보 → 장비 정확도 → log_physics)은 없어지고 ⑥ 3단계가 대신함4
  • Δ는 ⑥에서 ④의 90% 신뢰구간(CI, Confidence Interval)과 비교
