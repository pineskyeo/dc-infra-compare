• die마다 자기 평균을 빼면 측정 흔들림만 남는다.
  • 회차 이동(σ_run): 한 회차의 die가 다 같이 밀리는 크기. ⑤ 허용폭에 들어간다.
  • 반복 흔들림(σ_die): die 하나를 다시 잴 때 흔들리는 크기. ③ LoQ에 쓴다.
  • 튀는 die에 끌려가지 않게 평균 대신 중앙값을 쓴다.

σdie 와 σrun

eik = (xi,k+1 − xik) − mediani(xi,k+1 − xik) 이웃 회차 차이에서 회차 쌍의 공통 이동을 뺌 σdie = 1.4826 · median|e − median(e)| / √2 모든 die, 모든 쌍을 모아서 rj = mediani(xij − x̄i) 회차 j 의 공통 이동 σrun = √max(0, Var(r1 … rJ) − (π/2) · σdie² / n) σmeas = √(σdie² + σrun²), 측정 정밀도 = 100 · σmeas / |POR 중앙값| %

왜 중앙값과 MAD 인가

  • 표준편차는 평균에서 떨어진 거리를 제곱해 더한다. 크게 튀는 die 하나가 값을 크게 부풀린다.
  • MAD (중앙값 절대편차) 는 중앙값에서 떨어진 거리들의 중앙값이다. 가운데 거리만 보니 튀는 값 몇 개에 거의 안 움직인다.
  • × 1.4826 은 정규분포일 때 MAD 를 표준편차와 같은 크기로 맞춘다. 상수의 출처는 NIST e-Handbook 1.3.5.17 이다 (1.3.5.6 이 아님, 대조표 D5).
  • 회차 쌍마다 차이의 중앙값을 먼저 빼는 것은 회차 이동이 σdie 에 섞이지 않게 하려는 내부 설계다. 회차 이동을 따로 떼는 개념은 문헌에 있고, 중앙값과 (π/2)/n 보정은 이 SOP 의 근사다.
