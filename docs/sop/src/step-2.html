② 흔들림 구하기

이 쪽이 답하는 질문

같은 die를 다시 잴 때의 흔들림(반복성 σdie)과 회차(run)마다 모든 die가 함께 움직이는 크기(회차 이동 σrun)를 어떻게 나눠 구하나

쉬운 말로

  • 재료: ① 반복 측정의 die × 회차 표 중 기준 조건(Reference) J회 값만 씀. 판정은 측정 항목(ITEM)마다 따로라 σ도 ITEM마다 구함
  • die마다 원래 값이 다름(공정 산포). 같은 die끼리 빼면 이 차이가 지워지고 측정 흔들림만 남음
  • 반복성 σdie: 같은 die의 이웃 회차 차이(2회 − 1회, 3회 − 2회)에서 구함. 먼저 회차 전체가 함께 움직인 몫(차이의 중앙값)을 뺌
  • 회차 이동 σrun: 회차마다 'die 평균에서 떨어진 값'의 중앙값을 구하고, 그 값이 회차끼리 얼마나 다른지 봄. 그 안에 섞인 반복 흔들림 몫은 뺌
  • 평균·표준편차(SD, Standard Deviation) 대신 중앙값과 중앙값 절대편차(MAD, Median Absolute Deviation)를 씀
    • → 이상치 die 하나에 끌려가지 않음
  • 쓰는 곳: σdie
    • → ③ 정량한계(LoQ, Limit of Quantitation) 계산, σrun
    • → ⑤ 허용 범위 Δ의 회차 예측 한계
보충
  • 1.4826: 값이 정규분포를 따를 때 MAD를 표준편차로 바꾸는 상수1
  • ÷ √2: 두 번 잰 값의 차이는 1회 흔들림보다 √2배 큼 → 1회 크기로 되돌림2
  • (π/2)·σdie2/n: die n개의 중앙값이 반복 흔들림 때문에 흔들리는 몫(중앙값의 분산)4
  • 그림으로 보기: σdie와 σrun 나누기 · 중앙값 절대편차(MAD)

수식

eij = (xi,j+1 − xij) − mediani(xi,j+1 − xij)
σdie = 1.4826 · median|e − median(e)| / √2
rj = mediani(xij − x̄i)
σrun2 = Var(rj) − (π/2)·σdie2/n

이 단계의 기준

판정 없음 · 계산 단계

이상치 die가 있어도 중앙값·MAD로 추정해 끌려가지 않게 함

다음 단계로 넘기는 것

  • σdie → ③ 정량한계(LoQ)로 구간 나누기 σ = max(σdie, …)
  • σrun → ⑤ 허용 범위 Δ 정하기 t0.95, J−1·√(1 + 1/J)·σrun

그림

여기서 볼 것 · σrun이 0.25 → 3.0으로 커지면 Δ 중앙값이 5.654 → 13.494로 넓어짐 · b 0.8처럼 Δ에서 먼 차이는 동등 99.2% 이상 그대로 · σrun은 ⑤ 허용 범위 Δ를 직접 키우므로 회차마다 재터치다운해 제대로 잡아야 함 내부 기준(문헌 근거 없음)

반복성 σdie

  1. die 1 이웃 회차 차이 = 96.890 − 96.104 = 0.786, 96.465 − 96.890 = −0.425 예시 표 die 1 줄 · 기준 1~3회
  2. die 2~6도 같은 계산 → 위 차이 표 die 60개 전체에 같은 계산
  3. 회차 쌍별 차이의 중앙값 = 0.674(2회 − 1회) · 0.586(3회 − 2회)→ 각 쌍 차이에서 뺌 die 60개 전체의 쌍별 중앙값 = 회차 전체가 함께 움직인 몫
  4. 모두 모음 = 120개, 중앙값 0.0 die 60개 × 이웃 차이 2쌍
  5. MAD = 중앙값 0.0에서 떨어진 거리의 중앙값 = 0.944
  6. 1.4826 × 0.944 = 1.39957 1.4826 = MAD를 표준편차로 바꾸는 상수
  7. σdie = 1.39957 ÷ √2 = 0.98965 ≈ 0.990 √2 = 두 번 잰 값의 차이 → 1회

회차 이동 σrun

  1. 회차 평균(참고) = 99.4598100.0957100.7094 die 60개 전체, ① 반복 측정과 같은 값
  2. xij − x̄i(die 평균에서 떨어진 값)의 회차별 중앙값 rj = −0.451170.046330.60567 die 60개 전체 · 회차 1~3
  3. Var(rj) = 0.279543 rj 3개의 분산
  4. die 잡음 몫 = (π/2)·σdie2/n = 1.5708 × 0.989652 / 60 = 0.025641 (표준편차 0.16013) 1.5708 = π/2 · 0.98965 = 위 σdie · 60 = die 수
  5. σrun = √(0.279543 − 0.025641) = 0.50389 ≈ 0.504
  6. √ 안이 0보다 작으면(회차 평균 흔들림이 die 잡음 몫보다 작으면) σrun = 0으로 둠: σrun = √max(0, Var(rj) − (π/2)·σdie²/n) · 도구 계산과 같음 내부 기준(문헌 근거 없음)
  7. 넘김: σdie 0.98965 → ③, σrun 0.50389 → ⑤
