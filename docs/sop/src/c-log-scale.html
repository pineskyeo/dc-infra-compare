잡음이 값에 비례하면 log

이 쪽이 답하는 질문

어떤 ITEM을 log10|값|으로 판정하나(척도 log) · 그것을 무엇으로 알아보나

쉬운 말로

  • die마다 값 크기와 반복 잡음(같은 die를 다시 잰 흔들림)을 짝지어 봄
  • 잡음이 값과 상관없이 일정 → 기울기 0 → linear · 차이를 빼기(DOE − POR)로 봄
  • 잡음이 값에 비례 (값 10배 → 잡음 10배) → 기울기 1 → log · 차이를 비율(DOE ÷ POR)로 봄
  • log 축에서는 비례 잡음이 모든 die에서 같은 폭 → die를 한 잣대로 견줄 수 있음
  • 판정 길 log TOST = 척도 log + 부호 하나(양수만 · 음수만) · 1·2단계에서 동등이 아닌 ITEM만 ITEM 유형과 판정 길

그림

ITEM잡음 기울기선형 축 막대 길이 (긴 ÷ 짧은)log 축 막대 길이 (긴 ÷ 짧은)맞는 척도
잡음 일정≈ 0≈ 1.2배 (거의 같음)수십 배linear
잡음 ∝ 값≈ 1수십 배≈ 1.2배 (거의 같음)log

여기서 볼 것 · ① 위 그림에서 잡음 ∝ 값 ITEM은 오른쪽 위로 45°(기울기 1), 잡음 일정 ITEM은 수평(기울기 0) ② 아래 그림을 log 축으로 바꾸면 잡음 ∝ 값 ITEM의 막대 길이가 모두 같아짐 ③ 잡음 일정 ITEM은 반대로 선형 축에서 막대가 같음 → 막대가 같아지는 축이 그 ITEM의 척도

수식

die마다: x = log10(POR 회차 평균), y = log10(POR 회차 표준편차)
noise_slope = (x, y)에 맞춘 직선의 기울기 (Theil-Sen, 튀는 die에 강함)
spread_robust = 3.45 × IQR(log10|die 평균|) ≈ 값이 걸친 자릿수 (P1~P99)
spread_robust < 0.3 또는 기울기 못 구함 → 판별 불가
noise_slope ≥ 0.7 → log · 그 밖 → linear
scales 표에 그 ITEM 그룹의 log · linear가 적혀 있으면 표가 먼저 · 값이 걸친 폭이 좁으면(0.3 자릿수 = 약 2배 미만) 기울기를 믿을 수 없어 판별 불가

log TOST 허용폭

이동 = log10|DOE| − log10|POR| (die별 차이의 중앙값과 90% CI, 1단계와 같은 방법)
Δlog = log10(1 + r) + sigma_rep_log (판정에 씀)
Δlog_run = log10(1 + r) + t0.95, J−1·√(1 + 1/J)·σrun_log (참고 열 verdict_final_log_run만)
log10(1 + 0.05) = 0.0212 → 비율 5%가 log 공간에서 더하는 폭 · 두 허용폭 중 무엇을 쓸지는 결정 대기

내부 기준(문헌 근거 없음) 기울기 0.7, 폭 0.3 기준과 log 허용폭 · 용어 noise_slope · spread_robust · Δlog
