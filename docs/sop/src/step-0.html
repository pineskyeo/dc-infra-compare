식의 꼴은 문헌의 동등성 표본 크기 식이다. 문헌 예는 z0.95 + z0.90 이고 이는 검정력 80% 에 해당한다. 이 SOP 는 검정력 90% 를 목표로 z0.95 를 두 번 쓰고, d 의 흔들림을 √(1 + 1/J) 로 키운다 (대조표 D1, D2 를 고친 꼴). 최소 die 10개는 문헌 근거가 없는 내부 기준이다. 부호검정 90% 구간은 n = 5 부터 만들 수 있고, n = 10 이면 [d(2), d(9)] 이다.
