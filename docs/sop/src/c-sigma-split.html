• 같은 die를 다시 재도 값이 흔들린다 (σdie, die 반복).
  • 회차마다 모든 die가 같이 밀리기도 한다 (σrun, 회차 이동).
  • die를 많이 모으면 σdie 몫은 줄지만 σrun은 그대로 남는다.
  • 그래서 σdie는 LoQ에, σrun은 허용폭 Δ의 회차 몫에 쓴다.

쓰는 단계: ② 흔들림 나누기 · ③ LoQ · ⑤ 허용폭 Δ

σdie: 이웃 회차 차이의 MAD

yik = xi,k+1 − xik (k = 1 … J−1) die i 의 이웃 회차 차이 zik = yik − mediani(yik) 회차 쌍마다 die 전체 중앙값을 뺀다 MAD = median(|z − median(z)|) 중앙값 절대편차 σdie = 1.4826 · MAD / √2

회차 쌍마다 중앙값을 먼저 빼서 회차 이동이 차이에 섞이지 않게 한다 내부 기준. MAD는 가운데 거리만 보므로 튀는 값 몇 개에 거의 안 움직인다. 보통 표준편차 s = √(Σ(x − x̄)² / (n − 1))는 거리를 제곱해 더해 튀는 값 하나에 크게 부푼다. 1.4826 = 1/Φ⁻¹(0.75)는 정규분포에서 MAD를 표준편차 크기로 맞추는 배수이고, √2는 독립인 두 측정의 차이가 분산을 두 번 담기 때문이다.

σrun: 회차 중앙값의 퍼짐에서 die 잡음 몫을 뺀다

eij = xij − (xi1 + … + xiJ) / J die 평균에서 떨어진 값 rj = mediani(eij) 회차 j 의 중앙값 σrun = √max(0, Var(r1 … rJ) − (π/2)·σdie² / n)

회차 이동이 0이어도 rj는 die 잡음 때문에 흔들린다. n개 값의 중앙값 분산은 (π/2)·σ²/n 이라 그 몫을 뺀다. 뺀 값이 0보다 작으면 σrun = 0. 회차 성분을 따로 구하는 생각은 NIST의 3단 분산 분석과 같고, 평균 대신 중앙값을 쓰고 (π/2)/n로 보정하는 식은 이 방법의 변형이다.

왜 나누나

흔들림die를 늘리면쓰는 곳
σdie (die마다 따로)중앙값에 남는 몫이 √(π/2)·σdie/√n 로 준다LoQ = 10σ (③), 표본 크기 (⓪)
σrun (모든 die가 함께)줄지 않는다. DOE 회차도 같은 크기로 밀릴 수 있다Δ의 회차 몫 t·√(1+1/J)·σrun (⑤)
die 사이 퍼짐 (die마다 다른 고정 수준)POR와 DOE에 똑같이 들어가 die별 차이 d에서 빠진다쓰지 않음 내부 기준

둘을 하나로 합치면 die 수를 늘린 효과를 잘못 계산한다. die마다 값이 J개뿐이라 σ를 die별로는 믿을 수 없어, 두 값 모두 ITEM마다 모든 die를 모아 하나로 추정한다.

예시 계산 (예제 '정량 · 선형', EX_ITEM)

  • die 1 이웃 회차 차이: 96.890 − 96.104 = 0.786, 96.465 − 96.890 = −0.425
  • 회차 쌍별 중앙값 0.674 (2−1회), 0.586 (3−2회)를 빼고 die 60개 × 쌍 2개 = 120개를 모은다 → MAD = 0.944
  • σdie = 1.4826 × 0.944 / √2 = 0.98965 Ω
  • rj = −0.45117, 0.04633, 0.60567 → Var(rj) = 0.279543, die 잡음 몫 = 1.5708 × 0.98965² / 60 = 0.025641
  • σrun = √(0.279543 − 0.025641) = 0.50389 Ω (예제를 만든 회차 이동은 −0.5 / 0 / +0.5)

측정 정밀도 (참고 열, 판정에 안 씀)

σmeas = √(σdie² + σrun²) 측정 정밀도(%) = 100 · σmeas / |POR 중앙값| 중앙값이 0이면 빈칸 σmeas / Δ 미결 원인을 볼 때 쓰는 보조 열

독립인 두 산포는 분산이 더해진다. 3과 4를 합치면 √(3² + 4²) = 5 이고 단순 합 7이 아니다. 정밀도는 표준편차나 상대표준편차로 적고, 값이 클수록 나쁘다. 회차를 VIM의 중간 정밀도 조건에 대응시킨 것은 이 문서의 해석이다. 예제 '정량 · 선형': √(0.98965² + 0.50389²) = 1.1105 Ω → 1.11%. 산포가 0으로 나오면(분해능·고정값 문제) 좋은 값으로 읽지 않는다.
