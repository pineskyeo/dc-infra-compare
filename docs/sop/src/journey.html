ITEM 하나가 측정에서 판정까지 가는 길입니다. 유형을 고르고 ◀ ▶ 로 넘기면 같은 ITEM의 숫자가 ⓪부터 ⑦까지 이어집니다.

  • 숫자는 합성 데이터를 실제 판정 도구로 돌린 결과입니다.
  • 고른 유형은 다른 쪽으로 가도 이어집니다. 단계 쪽의 그림도 이 ITEM으로 바뀝니다.

예제 여섯 개는 어디서 오나

각 예제는 합성 POR·DOE 값을 판정 도구에 그대로 넣어 나온 items.csv 한 줄입니다. 쪽의 숫자와 그림은 모두 docs/sop/assets/journeys.js (window.SOP_JOURNEYS) 에서 읽고, 손으로 친 숫자는 없습니다.

python docs/sop/examples/journeys.py # 예제를 다시 만들어 journeys.js · journeys.json 을 씀 python docs/sop/examples/journeys.py --check # 판정 도구 결과와 다르면 실패
