• 허용폭의 5% 몫은 POR 중앙값에 비례한다.
  • 중앙값이 0에 가까우면 5% 몫도 0으로 줄어 Δ가 아주 좁아진다.
  • 그러면 같은 이동인데도 중앙값 때문에 미결·차이가 된다.
  • 0 근처는 고정 폭(LoQ), 계단은 값 간격 한 칸 이상을 쓴다. ⑥ 3단계에서만.

쓰는 단계: ⑤ 허용폭 Δ · ⑥ 판정 3단계

Δ가 무너지는 이유

Δ = r·|m| + t0.95, J−1·√(1+1/J)·σrun m → 0 ⇒ Δ → 회차 몫만 (σrun = 0 이면 Δ → 0)

이동 구간은 그대로인데 중앙값만 0에 가까워져도 동등 → 미결 → 차이로 바뀐다. 0 근처 값은 '몇 %'로 말하는 것이 뜻이 없어, ITEM 단위의 고정 폭으로 본다.

0 중심의 LoQ 와 그룹 abs_tol 은 값 크기와 상관없는 고정 폭이다. 계단의 기본값은 Δ 보다 좁아지지 않으니 Δ 와 함께 커진다. 계단은 POR 값 간격(resolution_step)이 0.1·Δ 이상인 ITEM이다. 한 칸보다 작은 이동은 볼 수 없으니 허용폭을 한 칸보다 좁게 두지 않는다. 장비 정확도 폭은 두 측정이 각자 사양 정확도 안에 있을 때 생길 수 있는 차이다. 기본값 규칙과 적용 대상은 내부 기준이다 내부 기준. --abs-tol 파일은 --groups 와 함께 줘야 한다.

판정

같은 90% 구간 [L, U] ⊂ [−abs_delta, +abs_delta] → 동등 구간 전체가 밖 → 차이, 걸침 → 미결 verdict_abs

구간은 1·2단계와 같고 허용폭만 바꾼다. 계단 ITEM은 구간 끝과 허용폭이 같은 격자 값이라 상대 오차 10⁻⁹ 안이면 같은 값으로 본다. 이 길은 1·2단계가 동등이 아닐 때만 쓴다. |m| < LoQ 인 0 중심 ITEM은 2단계 LoQ 판정을 먼저 한다.

  • 예제 '0 근처': 구간 +6.46 ~ +7.20 pA, abs_delta = LoQ 10.6 pA → 구간 전체가 ±10.6 pA 안 → 동등 (1·2단계는 Δ 0.27 pA 로 차이).
  • 예제 '계단 값': 구간 +2 ~ +4 µV, abs_delta = 값 간격 2 µV (Δ 1.57 µV 보다 큼) → 위 끝 4 µV 가 +2 µV 밖, 아래 끝은 안 → 미결 (경계).
