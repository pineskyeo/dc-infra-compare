내부 기준허용폭의 5% 몫

Δ 의 앞쪽 몫 r = 5%. 문헌이 정하는 값이 아니라 합의로 정할 값입니다.

지금: r = 0.05 (--r)

결정 대기log 허용폭 방식

log TOST 길에 회차 몫을 넣을지. 두 방식을 나란히 둡니다.

지금: Δlog 로 판정, Δlog_run 은 참고 열
