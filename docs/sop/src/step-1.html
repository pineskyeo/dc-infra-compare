• 같은 die를 POR 조건으로 J회, DOE 조건으로 1회 잰다.
  • 회차마다 프로브카드를 떼었다 다시 대고 잰다 (재터치다운).
  • die마다 d = DOE − POR 평균. 같은 die끼리 빼니 die 사이 차이가 지워진다.
  • 파일 모으기와 도구 실행은 실행 방법에.

짝지은 설계

xij = die i 의 POR j회 값 (j = 1 … J), yi = die i 의 DOE 값 x̄i = (xi1 + … + xiJ) / J di = yi − x̄i die i 의 차이 xij = die i 의 값 + 회차 j 이동 (σrun) + 반복 흔들림 (σdie)

같은 die 를 두 조건으로 재면 die 마다 쌍이 생기고, 쌍 차이 d 로 두 조건을 견준다. die 사이의 공정 산포는 빼기에서 지워지고 측정 흔들림만 남는다. POR 를 J회 평균으로 쓰는 것은 설계 선택이다.

입력 파일이 담을 것

  • POR 회차마다 파일 (또는 폴더) 하나, DOE 파일 하나. 같은 die 는 wafer · die 좌표 · ITEM 으로 짝짓는다.
  • POR 는 2회 이상, 권장 3회. 회차마다 재터치다운해야 회차 이동이 데이터에 들어간다. 연달아 재면 σrun 이 작게 잡혀 ⑤ 의 Δ 가 좁아진다 (내부 기준).
  • POR 모든 회차 파일과 DOE 파일에 다 있는 die 만 쓴다. 10개 미만이면 미결.
