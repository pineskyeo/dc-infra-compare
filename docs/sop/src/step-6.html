• 1단계: 90% 구간이 ±Δ 안이면 동등, 통째로 밖이면 차이, 걸치면 미결.
  • 2단계: LoQ 아래 ITEM만. DOE 구간이 LoQ 위로 통째로 넘지 않으면 동등.
  • 3단계: 앞이 동등이 아니면 판정 길로 다시 본다. 차이·미결이 다른 판정(예: 동등)으로 바뀔 수 있다.
  • die 10개 미만은 미결. die 몇 개만 바뀐 변화는 여기서 안 잡혀 튀는 die 수로 본다.

1단계 · 전체 TOST (모든 ITEM)

di = DOEi − (PORi1 + … + PORiJ) / J die i 의 차이 b = median(d1 … dn) 가운데 값 [L, U] = [d(k), d(n−k+1)] d 를 작은 것부터 세운 k번째, n−k+1번째 k = P(W ≤ k−1) ≤ 0.05 인 가장 큰 정수, W ~ 이항(n, ½) Δ = r·|m| + t0.95, J−1·√(1 + 1/J)·σrun r = 0.05

판정: −Δ ≤ L 이고 U ≤ Δ 이면 동등. L > Δ 이거나 U < −Δ 이면 차이. 그 밖은 미결이고, 반폭 (U − L)/2 ≥ Δ 이면 해상도 부족, 아니면 경계. 구간은 부호검정 구간이다. Δ의 5% 몫은 내부 기준, 회차 몫은 예측 한계 꼴.

2단계 · LoQ 판정 (|m| < LoQ 일 때)

DOE 구간 = [m + L, m + U] ① 이동이 ±Δ 안 (1단계 동등) → 동등 <LoQ 보고 일치 ② DOE 구간이 통째로 |x| ≥ LoQ 가 아님 → 동등 LoQ 아래이거나 LoQ 선에 걸침 ③ DOE 구간이 통째로 |x| ≥ LoQ, 이동이 ±Δ 밖 → 차이 ④ DOE 구간이 통째로 |x| ≥ LoQ, 이동이 ±Δ 에 걸침 → 미결

위에서부터 처음 맞는 줄을 쓴다. '<LoQ' 보고로 같다고 보는 규칙은 내부 기준이다. 이동은 LoQ 아래에서도 ±Δ 와 견줄 수 있다. LoQ 는 1회 측정값 하나의 한계이고, die 여러 개 d 의 중앙값은 die 하나보다 훨씬 정밀하기 때문이다 (⓪ 의 1/√n). 그래서 ① 처럼 이동이 ±Δ 안이면 보고 단위와 상관없이 동등이다.

3단계 · 판정 길 (1·2단계가 동등이 아닐 때)

판정 길은 POR 값만 보고 ③에서 정한다. 표의 위에서부터 처음 맞는 길을 쓴다.

최종 판정

1·2단계가 동등이면 그대로 확정. 아니면 판정 길의 판정이 동등 · 미결 · 차이 중 하나일 때 그것을 쓰고 (그래서 1·2단계의 차이·미결이 동등·미결·차이 어느 것으로도 바뀔 수 있다), 길이 판정하지 못하면 1·2단계 판정을 둔다. 판정을 정한 곳은 verdict_basis (linear, loq, log, accuracy, abs, limit) 에 적힌다.
