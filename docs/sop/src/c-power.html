검정력 90%와 표본 크기

이 쪽이 답하는 질문

실제로 같은데 미결이 나올 확률은 얼마이고, 이를 막으려면 die 수와 여유가 얼마나 있어야 하나

쉬운 말로

  • 검정력 = 실제로 같을 때 '동등'으로 나올 확률
  • 판정은 동등 / 차이 / 미결 셋6 내부 기준(문헌 근거 없음). 미결 = 같다고도 다르다고도 말할 수 없음
  • die가 모자라거나 σdie가 크면 신뢰구간(CI, Confidence Interval)이 넓어져 실제로 같아도 미결이 나옴
  • 그래서 die 수가 정해져 있으면 판별 가능한 최소 여유 (Δ−|b|)min을 먼저 계산(⓪)
  • Δ−|b|가 이 값보다 작으면 실제로 같아도 미결이 나오기 쉬움 → wafer 추가 또는 J 증가 검토
  • 아래 예시 값은 모두 합성 예시 측정 항목(ITEM) 하나의 값

수식

(Δ−|b|)min = 1.25 × (z0.95 + z0.95) × σdie × √(1+1/J) / √n

그림

실제로 같아도 미결이 나올 확률

여기서 볼 것 · σdie가 0.98965에서 8.0으로 커지면 CI 폭 중앙값이 0.613 → 4.959로 넓어지고 미결이 0.0% → 6.7%로 늘어남

die 수를 바꾸면 (σdie 6.0, 실제로 같음)

여기서 볼 것 · 같은 σdie 6.0에서 die 30개면 미결 9.6%, die 60개면 0.7%

편향 b를 바꾸면 (σdie 0.98965)

여기서 볼 것 · b가 Δ 중앙값 6.409 가까이(b 6) 오면 미결 20.6%, 차이 26.1%. 여유 Δ−|b|가 줄수록 미결이 늘어남

예시 계산

예시 데이터: 합성 예시 die 6개 표

z0.95가 두 번 들어가는 이유

  • z0.95 = 1.6449 (≈ 1.645): 정규분포에서 한쪽 5%를 남기는 값
  • 하나: 두 번의 한쪽 검정(TOST, Two One-Sided Tests)의 한쪽 5%7 ⑥의 90% 신뢰구간 = 양쪽 끝 5%씩
  • 다른 하나: 실제로 같을 때(b 0) 신뢰구간 끝이 +Δ 쪽이나 −Δ 쪽으로 넘어 미결이 되는 몫을 한쪽 5%로 묶음
    • → 두 쪽 합쳐 검정력 90% 내부 기준(문헌 근거 없음)
  • 문헌 식과 다른 점은 각주3

1.25 = √(π/2)

  • 편향 b는 d의 평균이 아니라 중앙값
  • 중앙값의 분산은 평균의 π/2배 → 중앙값 효율 2/π45 · 중앙값 효율 1.25
  • 표준편차로는 √(π/2) = 1.2533배 → 식에서 1.25

최소 여유 계산

  1. √(1+1/J) = √(1+1/3) = 1.1547 J = 3 = 기준 조건 반복 회차 수
  2. √n = √60 = 7.7460 n = 60 = 예시 die 수
  3. σdie = 0.98965 σdie와 σrun 예시 계산, ② 흔들림 구하기
  4. 최소 여유 = 1.25 × (1.6449 + 1.6449) × 0.98965 × 1.1547 / √60 = 0.6067
  5. σdie 1.0이면 0.613 1.0 = 예시 ITEM을 만든 값
  6. 예시 ITEM: Δ 6.699, |b| 0.786→ Δ−|b|가 0.6067보다 큼→ die 60개로 충분 6.699 = ⑤ Δ, 0.786 = ④ 편향 b
