• die가 적으면 90% 구간이 넓어, 실제로 같아도 미결이 나온다.
  • die를 늘리면 구간이 1/√n 꼴로 좁아진다.
  • 구간 반폭이 Δ보다 충분히 작아야 동등을 가려낸다.
  • 중앙값은 평균보다 약 1.25배 흔들려 die가 그만큼 더 든다.

쓰는 단계: ⓪ 표본 크기 정하기

최소 여유와 die 수

(Δ − |b|)min ≈ 1.25 · (z0.95 + z0.95) · σdie · √(1 + 1/J) / √n n ≈ ( 1.25 · (z0.95 + z0.95) · σdie · √(1 + 1/J) / (Δ − |b|) )²

식의 꼴은 동등성 검정의 표본 크기 식이다. 두 z의 뜻:

  • 하나는 TOST의 한쪽 5% (90% 구간의 한쪽 끝).
  • 다른 하나는 실제로 같을 때(b = 0) 구간 끝이 +Δ 쪽이나 −Δ 쪽으로 넘어 미결이 되는 몫. 양쪽 합쳐 10%로 묶어 검정력 90%가 된다. 문헌 예는 z0.90을 써서 검정력 80%이고, 이 문서는 90%를 목표로 z0.95를 쓴다 내부 기준.
  • √(1 + 1/J): d = DOE − POR J회 평균이라 die별 d의 반복 흔들림은 σdie·√(1 + 1/J)이다 (독립 분산의 합).
  • 1.25 = √(π/2): 평균 대신 중앙값을 쓰는 몫 (아래).

중앙값 효율 1.25

평균의 분산 = σ² / n 중앙값의 분산 ≈ (π/2) · σ² / n 정규분포, n 이 클 때 흔들림 비 √(π/2) = 1.2533 ≈ 1.25, 효율 2/π = 0.637

정규분포처럼 흩어지면 중앙값은 평균보다 1.25배 흔들리고, 같은 정밀도에 die가 π/2 = 1.57배 든다. 튀는 die에 끌려가지 않는 대가다. 같은 π/2가 σrun 식의 die 잡음 몫 (π/2)·σdie²/n 에도 나온다. 흩어짐이 정규분포가 아니면 이 배율도 달라진다.

구간 반폭 ÷ Δ (판정력)

ci_half_over_delta = (U − L) / 2 / Δ ≤ 0.5 안정, ≤ 0.8 주의, 그 위 불안정 judgeability

반폭이 Δ 이상이면 구간이 ±Δ 폭보다 넓어 동등이 나올 수 없다 (미결, 해상도 부족). 세 구간의 경계값은 모의실험으로 정한 내부 기준이다 내부 기준. die가 10개보다 적으면 판정하지 않는다.
