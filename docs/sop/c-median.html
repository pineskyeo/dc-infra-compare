중앙값과 평균

이 쪽이 답하는 질문

값 하나가 크게 튀어도 대표값이 끌려가지 않으려면 무엇을 쓰나 · 편향 b는 왜 die별 차이의 평균이 아니라 중앙값으로 구하나

쉬운 말로

  • 중앙값: 값을 크기순으로 놓았을 때 가운데 값. 평균: 값을 모두 더해 개수로 나눈 값
  • 값 하나가 크게 튀면 평균은 그쪽으로 끌려감. 중앙값은 순서만 보므로 거의 그대로
  • 예: 합성 예시 측정 항목(ITEM)의 die 5, 기준 조건(Reference) 3회 값 105.866 · 106.554 · 108.424에서 3회째만 높음
    • → 평균 106.9480, 중앙값 106.554 예시 데이터 표 die 5 · 예시 계산 1~2줄
  • 이 방법은 die 사이 대표값을 중앙값으로 잡음: 기준 조건 중앙값 100.000(③ 구간 나누기, ⑤ 실용 한계), 편향 b 0.78583(④)1 예시 계산 4~5줄
  • b의 재료 d = 비교 조건(Candidate) 값 − 기준 조건 3회 평균. die 하나 안의 기준 조건 회차(run) 3개는 평균, die 사이는 중앙값2
  • 튀는 die는 빼지 않고 개수만 기록. 중앙값을 쓰므로 빼지 않아도 결과가 크게 흔들리지 않음3
보충
  • 값이 정규분포처럼 고르게 퍼져 있으면 중앙값이 평균보다 조금 더 흔들림: 약 1.25배(= √(π/2))4. 그래서 ⓪ 표본 크기 정하기의 die 수 식에 1.25를 곱함
  • σdie도 중앙값을 바탕으로 한 중앙값 절대편차(MAD, Median Absolute Deviation)로 구함 → 표준편차 σ와 MAD

수식

중앙값 = x((n+1)/2) (n 홀수) · (x(n/2) + x(n/2+1)) / 2 (n 짝수)
평균 x̄ = (x1 + x2 + … + xn) / n
b = 중앙값(d1, d2, …, dn)
x(i) = 크기순 i번째 값. 중앙값은 순서만, 평균은 값의 크기를 모두 씀
기호뜻예시 값
x(i)크기순으로 놓았을 때 i번째 값die 5 기준 조건 3회의 x(2) = 106.554
n값 개수. die 사이에서는 die 수3(die 하나의 기준 조건 회차) · 60(die)
x̄평균106.9480(die 5 기준 평균)
ddie별 차이 = 비교 조건 값 − 기준 조건 J회 평균die 1: 0.7717
b편향. die 60개 d의 중앙값0.786
J기준 조건 반복 회차 수3

그림

여기서 볼 것 · 높게 튄 3회째 값 하나(die 5 108.424, die 6 97.106) 때문에 평균은 그쪽으로 끌려감(106.9480, 95.9650). 중앙값은 가운데 값 그대로(106.554, 95.404)5

합성 예시 · 전체 데이터 examples/example_wide.csv

  1. die 5 기준 조건 3회 크기순: 105.866 < 106.554 < 108.424→ 중앙값 = 2번째 값 106.554 n = 3 홀수라 가운데 2번째 · 표 die 5
  2. die 5 평균 = 106.9480 표 '기준 평균' 칸 = 3회 합 ÷ 3
  3. die 6 크기순: 95.385 < 95.404 < 97.106 → 중앙값 95.404, 평균 95.9650 표 die 6
  4. 기준 조건 중앙값 = 100.000 die 60개 전체 기준 평균의 중앙값 (60개 짝수라 30번째·31번째 값의 평균)
  5. b = d 60개의 중앙값 = 0.78583 ≈ 0.786 die 60개 d를 크기순으로 놓은 가운데
  6. 쓰는 곳: ④에서 b 0.786과 90% 신뢰구간(CI, Confidence Interval) [0.610, 1.102]를 구함. 구간 끝은 부호검정으로 고른 크기순 24번째·37번째 d ④ 차이(편향)와 90% 신뢰구간 구하기
  7. 쓰는 곳: ⑤ 실용 한계 = 5% × |100| = 5.0 ⑤ 허용 범위 Δ 정하기
