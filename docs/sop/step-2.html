② LoQ로 구간 나누기

LoQ를 구하고, |Ref|가 LoQ 이상이면 ⑤ TOST로, 미만이면 ⑥으로 보냅니다.

판정 기준

|Ref| ≥ LoQ인 정량 구간만 ⑤ TOST로 판정합니다.

자세히
C2-1판정 없음 · 계산 단계

LoQ → 구간 결정(아래 C2-2), ⑥ |Cand 중심| ≥ LoQ

C2-2

구간

구간조건판정 방법
정량|Ref| ≥ LoQ⑤ TOST
검출~정량LoD ≤ |Ref| < LoQ⑥ <LoQ 보고 일치
검출한계 이하|Ref| < LoD⑥ <LoQ 보고 일치 (LoD는 구간 이름만 나눔)

원문 확인 필요 · N5 구간 표는 "|Ref| ≥ LoQ", 판정 흐름은 "|Ref 중앙값| ≥ LoQ". 같은 뜻으로 보이나 표기가 다름.

수식

LoQ = 10·σ, σ는 네 후보 중 가장 큰 값입니다.

자세히
σ = max( σr, Δx데이터/√12, Δx장비/√12, σblank )
LoD = 3.29·σ LoQ = 10·σ LoQ = 1회 측정의 상대표준편차가 10%가 되는 크기
Δx: 분해능(값 사이 가장 작은 간격). 계단값이라 3회가 같으면 σr = 0이 되는 것을 막음. √12 = 반올림 오차의 표준편차
blank: 원측정값이라 CALCVAL로 ITEM 단위로 바꿀 수 있을 때만. LoQblank = |평균| + 10·SD

통과 조건

LoQ, LoD와 그것을 정한 쪽을 다음 단계로 넘깁니다.

자세히

por_median die별 기준 조건 3회 평균의 중앙값

LoQ · LoD · limit_source 정량한계, 검출한계와 그것을 정한 쪽 (기준 조건 반복 / 데이터 분해능 / 장비 분해능 / blank)

blank_item · blank_status · blank_LoQ_item · verdict_no_blank blank 관련

spec_status · level_check · range_por · range_doe · spec_resolution · accuracy_margin · verdict_no_accuracy item_info(LEVEL, CALCVAL, DERIVED) 관련 (②④)

흔한 예외

계단값(3회가 같으면 σr = 0) → Δx/√12

자세히
  • 계단값(3회가 같으면 σr = 0) → Δx/√12
  • blank는 CALCVAL로 ITEM 단위로 바꿀 수 있을 때만
  • LoD는 구간 이름만 나눔

유도·설명

LoQ는 1회 측정값을 숫자로 믿을 수 있는 최소 크기입니다.

자세히

목적 · 1회 측정값을 숫자로 믿을 수 있는 최소 크기입니다. 이보다 작은 값은 측정값을 그대로 기록하고 <LoQ 표시를 붙임(내부 기준).

  • 정량한계 LoQ 10σ: 1회 측정값을 숫자로 믿을 수 있는 최소 크기
  • √12 = 반올림 오차의 표준편차
  • 장비 분해능은 item_info의 LEVEL·CALCVAL로 range 결정
