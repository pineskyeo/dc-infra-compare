중앙값 90% 구간 구하기

구간 끝 순위를 정하는 계산.

  • die마다 차이 d = DOE − POR 평균을 구해 작은 것부터 세운다.
  • 가운데 값(중앙값)은 크게 튄 die 하나에 끌려가지 않는다.
  • 양 끝에서 같은 수만큼 떼고 남은 범위가 90% 구간이다.
  • 구간 끝도 순위로 정해 튄 값의 크기에 흔들리지 않는다.

쓰는 단계: ④ 변화 구간 · ⑥ 판정 3단계

90%는 무슨 뜻인가

d의 참 중앙값 m은 정해진 하나의 수이지만 모른다. die를 새로 뽑아 다시 재면 구간이 매번 조금씩 달라진다. 같은 실험을 100번 해서 구간을 100개 만들면 약 90개가 m을 덮는다. 움직이는 것은 구간이고 m은 그대로다. 측정한 중앙값 b는 늘 자기 구간 안에 있으니, 90%가 말하는 대상은 b가 아니라 m이다. 구간 폭은 90%와 따로, die 수와 d의 흩어짐이 정한다.

수식

di = DOEi − (PORi1 + … + PORiJ) / J die i 의 차이 b = median(d1 … dn) B ~ 이항(n, ½) d 가 m 보다 작은 die 수 (동전 n번의 앞면 수) k = P(B ≤ k−1) ≤ 0.05 인 가장 큰 정수 [L, U] = [d(k), d(n−k+1)] 작은 것부터 k번째, n−k+1번째 포함 확률 = 1 − 2·P(B ≤ k−1)

m은 중앙값이라 die 하나의 d가 m보다 작을 확률이 ½이다. 그래서 'm보다 작은 die 수'는 동전 n번의 앞면 수와 같은 꼴이다. m이 구간 밖에 있는 경우는 둘뿐이다: m보다 작은 die가 k−1개 이하이거나, 큰 die가 k−1개 이하. 각각 확률이 P(B ≤ k−1)이고, 이것이 5% 이하인 가장 큰 k를 고른다1. 값의 크기는 쓰지 않고 순번만 쓰니 d의 분포 모양을 가정하지 않는다. 이 생각이 부호검정이다. d를 die마다 짝지어 만드는 것은 같은 대상을 두 조건으로 잰 쌍 설계다2.

순번은 정수라 포함 확률이 딱 90%가 되지 않고, 90% 이상인 것 중 가장 좁은 짝을 쓴다. 엑셀로는 =BINOM.DIST(k−1, n, 0.5, TRUE)를 k를 올려 가며 계산해 5% 이하인 마지막 k를 찾는다. 같은 값의 d가 여럿이면 순번만 센다.

예시 계산 (예제 '정량 · 선형', n = 60)

  • P(B ≤ 23) = 4.62% ≤ 5% < P(B ≤ 24) = 7.75% → k = 24
  • 구간 = [d(24), d(37)] = [0.610, 1.10233] Ω, 포함 확률 = 1 − 2 × 0.04623 = 90.75%
  • b = (30번째 0.785 + 31번째 0.78667) / 2 = 0.78583 Ω
  • d 평균은 0.8758 Ω. 가장 큰 d가 100이 되어도 24번째·37번째 값과 중앙값은 그대로다

중앙값을 쓰는 대가

평균의 90% 구간 ≈ ±1.645 · σ / √n 중앙값의 90% 구간 ≈ ±1.645 · √(π/2) · σ / √n √(π/2) = 1.2533

d가 정규분포처럼 흩어지면 중앙값은 평균보다 √(π/2) ≈ 1.25배 더 흔들려 구간이 약 25% 넓다3. 대신 분포 모양을 몰라도 되고 튀는 die 몇 개에 흔들리지 않는다. 튀는 die는 빼지 않고 개수만 센다: |d − median(d)| > 5 × robust σ 이면 n_outlier_die에 더한다4. 튀는 die의 크기는 구간에 영향이 없지만, 개수가 늘면 순번이 밀려 구간이 바뀐다.
