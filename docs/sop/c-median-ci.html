개념 익히기 › 중앙값의 90% 신뢰구간 (개념 7 / 19) · 쓰는 단계 ④

중앙값의 90% 신뢰구간(CI, Confidence Interval)은 어떻게 구하나

이 쪽이 답하는 질문

die 60개 합성 예시 측정 항목(ITEM)의 die 수 n의 차이 d로 진짜 중앙값이 어디쯤인지 범위를 어떻게 정하나 · 이 범위가 90% 신뢰구간(CI, Confidence Interval) 90% = ④에서 쓰는 신뢰 수준

먼저: 90%는 무슨 뜻인가

  • 진짜 중앙값(참값) m은 정해진 하나의 수 · 다만 아무도 모름 예: 참값 0.8이라고 가정
  • die를 새로 뽑아 다시 재면 CI도 매번 조금씩 달라짐 예: [0.6, 1.1], [0.5, 0.9], [0.7, 1.2] …
  • 같은 실험을 100번 반복해 CI를 100개 만들면 → 약 90개는 참값 0.8을 포함, 약 10개는 놓침 놓친 예: [0.85, 1.3]5
  • 90% = 이 방법이 참값을 잡아내는 성공률 · 움직이는 것은 구간, 참값은 그대로
  • 측정한 중앙값 b(예시 0.786)는 늘 자기 CI 안에 있음 → 90%가 말하는 대상은 b가 아니라 모르는 참값 m
  • CI 폭은 90%와 별개 · 폭은 die 수와 die 간 흔들림이 정함 → die 수별 폭은 아래 그림

CI와 TOST는 다른 것

  • CI = 참값이 있을 만한 범위만 알려 줌 · 판정은 안 함 예: 참 차이는 아마 0.610 ~ 1.102
  • 두 번의 한쪽 검정(TOST, Two One-Sided Tests) = CI를 허용 범위 ±Δ와 비교해 판정하는 규칙 · 통째로 안 → 동등, 통째로 밖 → 차이, 걸침 → 미결
  • 비유: CI는 자로 잰 길이, TOST는 그 길이로 규격 합격을 정하는 규칙
  • 90%를 쓰는 이유: TOST는 '+Δ보다 작다', '−Δ보다 크다'를 각각 5% 오류로 확인 → 두 확인을 합친 것 = 90% CI가 ±Δ 안에 있는지6 · 판정은 TOST와 동등 · 차이 · 미결

한 줄 요약 · 90% CI = 같은 실험을 100번 하면 약 90번은 모르는 참값을 덮는 구간

쉬운 말로

그림으로 먼저: d → 진짜 중앙값 m → 동전 → 양끝 자르기

  • 그림 1: die마다 차이 d = 비교 조건(Candidate) 값 − 기준 조건(Reference) 3회 평균부터 만듦 · 기준 조건 값(100 근처)과 비교하는 것이 아님
  • 그림 2: d들의 진짜 중앙값 m(= 진짜 차이)을 기준으로 die 하나가 위냐 아래냐 → 동전 한 번
  • 그림 3: 동전 60번의 확률로 양끝을 몇 개 뗄지 정함 → 남은 구간이 90% CI
d 계산 (die 1~5)
  1. die 1: 기준 3회 평균 = (96.104 + 96.890 + 96.465) / 3 = 96.4863d = 97.258 − 96.4863 = +0.7717
  2. die 2: 기준 3회 평균 = (99.194 + 98.516 + 100.005) / 3 = 99.2383d = 101.005 − 99.2383 = +1.7667
  3. die 3: 기준 3회 평균 = (94.828 + 95.894 + 95.134) / 3 = 95.2853d = 96.819 − 95.2853 = +1.5337
  4. die 4: 기준 3회 평균 = (102.294 + 101.657 + 102.060) / 3 = 102.0037d = 101.415 − 102.0037 = −0.5887
  5. die 5: 기준 3회 평균 = (106.554 + 105.866 + 108.424) / 3 = 106.9480d = 107.455 − 106.9480 = +0.5070

여기서 볼 것 · 비교하는 것은 die별 차이 d · 기준 조건 값 자체(95 ~ 107)는 d를 만들고 나면 더 안 씀

  • m = d들의 진짜 중앙값 = 두 조건의 진짜 차이 → 뜻 자체가 '절반은 아래, 절반은 위'
  • 그래서 die 하나의 d가 m보다 아래일 확률 = 1/2 → 동전 앞면 확률과 같음
  • m 아래 die 수 B = 동전 n번의 앞면 수 → 이항분포(Binomial distribution)를 따름 이번 10개: 아래 -1.050, -0.589, 0.507, 0.610, 0.727, 0.772 → B = 6

여기서 볼 것 · m 위치는 몰라도 'die마다 위·아래 반반'은 확실 → 이 사실 하나로 범위를 잡음

  1. 한쪽 꼬리 P(B ≤ 23) = Σi=0..23 C(60, i) / 260 = 0.04623 = 4.62% ≤ 5%P(B ≤ 24) = 0.07750 = 7.75% > 5% → k = 23
  2. 반대쪽 P(B ≥ 37) = 뒷면 23번 이하 = 같은 4.62%두 꼬리 합 = 2 × 0.04623 = 0.09246 ≈ 9.25%
  3. 실제 신뢰도 = 1 − 0.09246 = 0.90754 → 90.75%
  4. 남은 구간 = 23+1 = 24번째 ~ 60 − 23 = 37번째 = [0.610, 1.102] 아래 '예시 계산'과 같은 값

여기서 볼 것 · 동전이 한쪽으로 몰리는 드문 경우(각 4.62%)만 m이 구간 밖 → 양끝 23개씩 떼고 남은 [0.610, 1.102]가 90% CI

말로 정리

  • d: die마다 비교 조건(Candidate) 값 − 기준 조건(Reference) 3회 평균 합성 예시는 기준 조건 3회(J = 3) · d 60개의 진짜 중앙값 m은 모름
    • → die를 다시 뽑아 재면 중앙값이 조금씩 달라짐
    • → m이 있을 만한 범위가 필요
  • die마다 d가 진짜 중앙값 m보다 작게 나올 확률은 반반 m이 중앙값이라 절반은 아래, 절반은 위
    • → 'm보다 작은 die 수' = '동전 60번 던졌을 때 앞면 수(B)'와 같은 꼴1 · 동전 비유 내부 기준(문헌 근거 없음)
  • d를 크기순으로 세우고 양끝에서 k개씩 떼면 → 남은 구간 = 아래에서 k+1번째 값 ~ n−k번째 값
  • 진짜 중앙값이 남은 구간 밖에 있는 경우는 둘뿐: 'm보다 작은 die가 k개 이하(앞면이 k번 이하)' 또는 'm보다 큰 die가 k개 이하(뒷면이 k번 이하)'
    • → 두 쪽 확률이 같아 각각 한쪽 P(B ≤ k)2
  • 한쪽 P(B ≤ k)가 5% 이하인 가장 큰 k를 고름 5% × 2쪽 = 10% → 남은 90%
    • → die 60개면 k = 23, 구간은 24번째 ~ 37번째 값, 실제 신뢰도 90.75% 예시 계산 1~3줄12
  • 값의 크기는 쓰지 않고 순번만 씀 → 부호검정과 같은 생각 · 판정에서의 쓰임은 부호검정과 중앙값 90% 신뢰구간
보충
  • 실제 신뢰도가 딱 90%가 아닌 이유: k는 정수
    • → 고를 수 있는 신뢰도가 몇 개뿐
    • → 90% 이상 중 가장 가까운 값을 씀1
  • die 수가 바뀔 때 k 찾는 법: 엑셀 =BINOM.DIST(k, n, 0.5, TRUE)를 k를 1씩 올리며 계산
    • → 5% 이하인 마지막 k
    • → 구간 = k+1번째 ~ n−k번째 값
  • die 수별 결과 (같은 규칙)
    die 수 n남은 구간 순번실제 신뢰도
    3011 ~ 20번째90.13%
    4517 ~ 29번째92.75%

  • 같은 값의 d가 여럿일 때: 크기순 순번만 셈 → 구간 끝은 그 순번에 놓인 값 내부 기준(문헌 근거 없음)

작은 예시 먼저: die 10개

  1. die 10개의 d를 크기순으로 세우고 양끝에서 1개씩 뗌(k = 1)→ 남은 구간 = 2번째 ~ 9번째 값 k + 1 = 2, n − k = 10 − 1 = 9
  2. 진짜 중앙값이 2번째 값보다 아래 = m보다 작은 die가 0개 또는 1개 = 동전 10번에서 앞면 0번 또는 1번
  3. 앞면 0번 = C(10, 0) = 1가지앞면 1번 = C(10, 1) = 10가지전체 = 210 = 1024가지 동전 10번의 앞뒤 경우 수
  4. 한쪽 바깥 확률 = P(B ≤ 1) = (1 + 10)/1024 = 11/1024 = 1.07% ≈ 1.1%
  5. 반대쪽(뒷면 1번 이하)도 같은 1.1%
  6. 실제 신뢰도 = 1 − 2 × 11/1024 = 1002/1024 = 97.85% ≈ 97.9%

수식

P(B = i) = C(60, i) / 260
P(B ≤ k) = Σi=0..k C(60, i) / 260
90% CI = [d(k+1), d(n−k)]
실제 신뢰도 = 1 − 2·P(B ≤ k)
k = P(B ≤ k) ≤ 5%인 가장 큰 수
앞면이 i번 나오는 가짓수를 전체 가짓수로 나눔 → 0번부터 k번까지 더하면 한쪽 바깥 확률 → 양쪽을 빼면 실제 신뢰도
기호뜻예시 값
ndie 수60
d(i)d(die별 차이 = 비교 조건 − 기준 조건 3회 평균)를 작은 값부터 세웠을 때 i번째 값d(24) = 0.610
md의 진짜 중앙값. 알 수 없는 값이라 구간으로 잡음모름 · 추정값 b = 0.786
Bd가 m보다 작게 나온 die 수. 동전 n번 던졌을 때 앞면 수와 같은 꼴0 ~ 60
C(n, i)n번 중 앞면이 i번 나오는 가짓수C(10, 1) = 10

그림

여기서 볼 것 · 실제 신뢰도 90% 이상 중 가장 좁은 구간은 k 23 · k 22 → 94.81% · 폭 0.632 / k 23 → 90.75% · 폭 0.492 / k 24 → 84.50%로 90% 미만

정규분포와 비교

  • 데이터 90% 범위 = ±1.645σ: die 하나의 d가 들어갈 범위 · 중앙값의 범위가 아님 σ = d의 흔들림
  • 평균의 90% CI ≈ ±1.645 × σ/√60 = ±0.2124σ ≈ ±0.21σ √60 = 7.746
  • 중앙값의 90% CI ≈ ±1.645 × 1.2533 × σ/√60 = ±0.2662σ ≈ ±0.27σ 1.2533 = √(π/2), 중앙값 효율 1.253
  • 0.2662 / 0.2124 = 1.2533 → 정규분포일 때 중앙값 CI가 평균 CI보다 약 25% 넓음
  • 쉬운 말로: 데이터 범위는 die 하나가 어디 떨어질지, CI는 60개를 모아 낸 중앙값 하나가 어디 있을지
    • → 모아 낸 값이라 범위가 훨씬 좁음(±1.645σ 대 ±0.27σ) 내부 기준(문헌 근거 없음)
  • 이 쪽의 순번 방법은 정규분포를 가정하지 않음 → 위 식은 넓이를 견주는 데만 씀

왜 이 방법을 쓰나

  • 분포 가정 없음: 'm보다 작을 확률 반반'만 씀 → d가 정규분포가 아니어도 같은 규칙1
  • 튀는 die의 크기에는 안 흔들림: 순번만 씀
    • → 가장 큰 die의 d 3.9643이 100이 되어도 24번째·37번째 값은 그대로 3.9643 = 예시 ITEM d 60개 중 가장 큰 값
  • 튀는 die의 개수는 영향 있음: 개수가 늘면 순번이 밀려 구간이 바뀜
  • 대신 정규분포일 때 평균 CI보다 약 25% 넓음 (±0.27σ 대 ±0.21σ)
  • 손해와 이득: 정규분포일 때 구간이 약 25% 넓어지는 손해 ↔ 분포 모양을 몰라도 되고 튀는 die 몇 개에 안 흔들리는 이득 내부 기준(문헌 근거 없음)
  • 도구도 같은 규칙으로 계산 → ④ 차이(편향)와 90% 신뢰구간 구하기의 구간 [0.610, 1.102]
