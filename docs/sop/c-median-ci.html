개념 익히기 › 중앙값의 90% 신뢰구간 (개념 7 / 14) · 쓰는 단계 ④

중앙값의 90% 신뢰구간(CI, Confidence Interval)은 어떻게 구하나

이 쪽이 답하는 질문

die 60개 합성 예시 측정 항목(ITEM)의 die 수 n의 차이 d로 진짜 중앙값이 어디쯤인지 범위를 어떻게 정하나 · 이 범위가 90% 신뢰구간(CI, Confidence Interval) 90% = ④에서 쓰는 신뢰 수준

쉬운 말로

  • d: die마다 비교 조건(Candidate) 값 − 기준 조건(Reference) 3회 평균 합성 예시는 기준 조건 3회(J = 3) · d 60개의 진짜 중앙값 m은 모름
    • → die를 다시 뽑아 재면 중앙값이 조금씩 달라짐
    • → m이 있을 만한 범위가 필요
  • die마다 d가 진짜 중앙값 m보다 작게 나올 확률은 반반 m이 중앙값이라 절반은 아래, 절반은 위
    • → 'm보다 작은 die 수' = '동전 60번 던졌을 때 앞면 수(B)'와 같은 꼴1 · 동전 비유 내부 기준(문헌 근거 없음)
  • d를 크기순으로 세우고 양끝에서 k개씩 떼면 → 남은 구간 = 아래에서 k+1번째 값 ~ n−k번째 값
  • 진짜 중앙값이 남은 구간 밖에 있는 경우는 둘뿐: 'm보다 작은 die가 k개 이하(앞면이 k번 이하)' 또는 'm보다 큰 die가 k개 이하(뒷면이 k번 이하)'
    • → 두 쪽 확률이 같아 각각 한쪽 P(B ≤ k)2
  • 한쪽 P(B ≤ k)가 5% 이하인 가장 큰 k를 고름 5% × 2쪽 = 10% → 남은 90%
    • → die 60개면 k = 23, 구간은 24번째 ~ 37번째 값, 실제 신뢰도 90.75% 예시 계산 1~3줄12
  • 값의 크기는 쓰지 않고 순번만 씀 → 부호검정과 같은 생각 · 판정에서의 쓰임은 부호검정과 중앙값 90% 신뢰구간
보충
  • 실제 신뢰도가 딱 90%가 아닌 이유: k는 정수
    • → 고를 수 있는 신뢰도가 몇 개뿐
    • → 90% 이상 중 가장 가까운 값을 씀1
  • die 수가 바뀔 때 k 찾는 법: 엑셀 =BINOM.DIST(k, n, 0.5, TRUE)를 k를 1씩 올리며 계산
    • → 5% 이하인 마지막 k
    • → 구간 = k+1번째 ~ n−k번째 값
  • die 수별 결과 (같은 규칙)
    die 수 n남은 구간 순번실제 신뢰도
    3011 ~ 20번째90.13%
    4517 ~ 29번째92.75%
    6024 ~ 37번째90.75%
    9037 ~ 54번째92.75%
  • 같은 값의 d가 여럿일 때: 크기순 순번만 셈 → 구간 끝은 그 순번에 놓인 값 내부 기준(문헌 근거 없음)

작은 예시 먼저: die 10개

  1. die 10개의 d를 크기순으로 세우고 양끝에서 1개씩 뗌(k = 1)→ 남은 구간 = 2번째 ~ 9번째 값 k + 1 = 2, n − k = 10 − 1 = 9
  2. 진짜 중앙값이 2번째 값보다 아래 = m보다 작은 die가 0개 또는 1개 = 동전 10번에서 앞면 0번 또는 1번
  3. 앞면 0번 = C(10, 0) = 1가지앞면 1번 = C(10, 1) = 10가지전체 = 210 = 1024가지 동전 10번의 앞뒤 경우 수
  4. 한쪽 바깥 확률 = P(B ≤ 1) = (1 + 10)/1024 = 11/1024 = 1.07% ≈ 1.1%
  5. 반대쪽(뒷면 1번 이하)도 같은 1.1%
  6. 실제 신뢰도 = 1 − 2 × 11/1024 = 1002/1024 = 97.85% ≈ 97.9%

수식

P(B = i) = C(60, i) / 260
P(B ≤ k) = Σi=0..k C(60, i) / 260
90% CI = [d(k+1), d(n−k)]
실제 신뢰도 = 1 − 2·P(B ≤ k)
k = P(B ≤ k) ≤ 5%인 가장 큰 수
앞면이 i번 나오는 가짓수를 전체 가짓수로 나눔 → 0번부터 k번까지 더하면 한쪽 바깥 확률 → 양쪽을 빼면 실제 신뢰도

ndie 수60
d(i)d(die별 차이 = 비교 조건 − 기준 조건 3회 평균)를 작은 값부터 세웠을 때 i번째 값d(24) = 0.610
md의 진짜 중앙값. 알 수 없는 값이라 구간으로 잡음모름 · 추정값 b = 0.786

그림

여기서 볼 것 · 실제 신뢰도 90% 이상 중 가장 좁은 구간은 k 23 · k 22 → 94.81% · 폭 0.632 / k 23 → 90.75% · 폭 0.492 / k 24 → 84.50%로 90% 미만

정규분포와 비교

  • 데이터 90% 범위 = ±1.645σ: die 하나의 d가 들어갈 범위 · 중앙값의 범위가 아님 σ = d의 흔들림
  • 평균의 90% CI ≈ ±1.645 × σ/√60 = ±0.2124σ ≈ ±0.21σ √60 = 7.746
  • 중앙값의 90% CI ≈ ±1.645 × 1.2533 × σ/√60 = ±0.2662σ ≈ ±0.27σ 1.2533 = √(π/2), 중앙값 효율 1.253
  • 0.2662 / 0.2124 = 1.2533 → 정규분포일 때 중앙값 CI가 평균 CI보다 약 25% 넓음
  • 쉬운 말로: 데이터 범위는 die 하나가 어디 떨어질지, CI는 60개를 모아 낸 중앙값 하나가 어디 있을지
    • → 모아 낸 값이라 범위가 훨씬 좁음(±1.645σ 대 ±0.27σ) 내부 기준(문헌 근거 없음)
  • 이 쪽의 순번 방법은 정규분포를 가정하지 않음 → 위 식은 넓이를 견주는 데만 씀

왜 이 방법을 쓰나

  • 분포 가정 없음: 'm보다 작을 확률 반반'만 씀 → d가 정규분포가 아니어도 같은 규칙1
  • 튀는 die의 크기에는 안 흔들림: 순번만 씀
    • → 가장 큰 die의 d 3.9643이 100이 되어도 24번째·37번째 값은 그대로 3.9643 = 예시 ITEM d 60개 중 가장 큰 값
  • 튀는 die의 개수는 영향 있음: 개수가 늘면 순번이 밀려 구간이 바뀜
  • 대신 정규분포일 때 평균 CI보다 약 25% 넓음 (±0.27σ 대 ±0.21σ)
  • 손해와 이득: 정규분포일 때 구간이 약 25% 넓어지는 손해 ↔ 분포 모양을 몰라도 되고 튀는 die 몇 개에 안 흔들리는 이득 내부 기준(문헌 근거 없음)
  • 도구도 같은 규칙으로 계산 → ④ 차이(편향)와 90% 신뢰구간 구하기의 구간 [0.610, 1.102]
