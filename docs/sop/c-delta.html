허용 범위 Δ

이 쪽이 답하는 질문

어디까지 달라도 '같다'고 보나 · Δ = |기준 조건(Reference) 중앙값|의 5% + 회차 예측 한계에서 3.3717과 σrun 0.50389는 어디서 오나

쉬운 말로

  • Δ: 편향이 이 안이면 같다고 보는 폭. 실무상 괜찮은 차이와 기준 조건을 다시 재도 생기는 차이를 함께 허용함
  • 실용 한계 5%: 이만큼은 달라도 실무상 같다고 봄2 내부 기준(문헌 근거 없음)
  • 회차 예측 한계: 기준 조건을 다시 재기만 해도 생기는 차이. 이보다 작은 차이를 '차이'로 부르지 않게 함1
  • 회차 예측 한계 = 계수 × σrun. 계수는 반복 횟수 J로 정해지고(J 3이면 3.3717), σrun은 ② 흔들림 구하기에서 구한 회차 이동(예시 0.50389) 둘의 유래는 아래 수식 절
  • 장비 정확도 한계가 있는 A·V 측정 항목(ITEM)이 바닥 근처이고 ⑥ 3단계 판정 길이 선형 TOST면, Δ(실용 한계 + 회차 예측 한계)와 장비 정확도 한계 중 큰 값으로 다시 판정. 1·2단계의 Δ는 그대로 · 예전 accuracy 옵션은 없어지고 3단계가 대신함 · 다른 허용폭: 절대 허용폭 · log 허용폭3
  • Δ의 두 조각(실용 한계 5% × |기준 조건 중앙값|, 회차 예측 한계 계수 × σrun)은 Δ를 만드는 재료일 뿐. 허용 범위는 0을 가운데 둔 −Δ ~ +Δ 예시: 0.05 × 100 = 5.0, 3.3717 × 0.50389 = 1.69896 → Δ = 6.699 → 허용 범위 −6.699 ~ +6.699

더 자세한 쉬운 말은 아래 쉬운 말 더 보기

보충

3.3717은 어디서 오나

  • t0.95, 2 = 2.919986: σrun을 회차(run) 3번(J 3)만으로 추정하니 자유도(df, degrees of freedom) J−1 = 2인 t 분포의 한쪽 95% 값을 씀. 회차가 적을수록 t가 커져 한계가 넓어짐
  • √(1+1/3) = 1.154701: 앞으로 잴 회차 하나의 흔들림(1)과 기준 조건 3회 평균의 흔들림(1/3)을 합친 것 내부 기준(문헌 근거 없음)
  • 3.3717 = 2.919986 × 1.1547011

σrun 0.50389는 어디서 오나

  • ② 흔들림 구하기에서 구함. 방법 설명은 σdie와 σrun 나누기
  • 회차마다 각 die 값에서 die 평균을 빼고 중앙값을 냄: rj = [−0.45117, 0.04633, 0.60567]
  • 세 값의 분산 Var(rj) = 0.279543. 여기에는 die 잡음 몫 (π/2)·σdie²/n = 1.5708 × 0.98965² / 60 = 0.025641도 섞여 있음4
  • σrun = √(0.279543 − 0.025641) = 0.50389 ≈ 0.504
  • 예시 ITEM을 만들 때 넣은 회차 이동은 −0.5 / 0 / +0.5. 도구는 회차 3번에서 0.504로 추정

그림

여기서 볼 것 · σrun이 커지면 Δ가 넓어져(0.25에서 5.8429, 3.0에서 15.1151), 실용 한계 5.0보다 큰 실제 이동 b 5.5도 '동등'으로 나오는 비율이 40.9%에서 93.2%로 늘어남. 회차 이동이 크면 Δ가 너그러워짐 → ⓪에서 회차 예측 한계를 5% 안에 묶는 이유

쉬운 말 더 보기

  • 예시: Δ = 5.0 + 1.69896 = 6.699. 0을 가운데 두고 ±6.699 안이면 같다고 봄 예시 계산 1~5줄

예시 계산

예시 데이터: 합성 예시 die 6개 표

  1. 실용 한계 = 5% × |100| = 5.0 100 = die 60개 전체 기준 평균의 중앙값
  2. 3.3717 = t(0.95, 2) 2.919986 × √(1+1/3) 1.154701 J = 3이라 t의 자유도 J−1 = 2
  3. σrun = √(0.279543 − 0.025641) = 0.50389 ② 흔들림 구하기: 회차 중앙값의 분산 0.279543에서 die 잡음 몫 0.025641을 뺌
  4. 회차 예측 한계 = 3.3717 × σrun 0.50389 = 1.69896
  5. Δ = 5.0 + 1.69896 = 6.69896 ≈ 6.699
  6. 쓰는 곳: ⑥ 두 번의 한쪽 검정(TOST, Two One-Sided Tests)에서 90% 신뢰구간(CI, Confidence Interval) [0.610, 1.102] ⊂ (−6.699, +6.699)→ 동등 [0.610, 1.102] = ④ 차이(편향)와 90% 신뢰구간 구하기
