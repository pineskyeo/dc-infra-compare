허용 범위 Δ

편향이 이 안이면 같다고 보는 폭. Δ = |기준 조건 중앙값|의 5% + 회차 예측 한계

왜 쓰나

실무상 괜찮은 차이와 기준 조건을 다시 재도 생기는 차이를 함께 허용함

자세히
  • 5%(실용 한계): 이만큼은 달라도 실무상 같다고 봄 내부 기준
  • 회차 예측 한계: 기준 조건을 다시 재기만 해도 생기는 차이. 이보다 작은 차이를 '차이'로 부르지 않게 함
  • 장비 정확도 한계를 쓰는 항목(A·V ITEM)은 둘 중 큰 값

그림

5.0 + 1.686 = 6.686, 0을 가운데 두고 ±6.686이 허용 범위

자세히

예시 숫자

기준 조건 중앙값 100.0이면 Δ = 6.686

자세히
5% × 100.0 = 5.0
3.3717 × 0.5 = 1.686 (J = 3, σrun 0.5)
Δ = 5.0 + 1.686 = 6.686

합성 예시이며 실행 결과가 아닙니다.
